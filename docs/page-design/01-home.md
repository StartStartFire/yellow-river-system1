# 首页页面设计说明

## 1. 页面名称

```text
首页
```

## 2. 页面定位

首页是“黄河上游水库群调度系统”的系统总览页，用于展示黄河上游水库群整体运行态势、水情监控、发电统计、流域地图、过程曲线、预警信息和系统公告。

首页强调：

```text
流域总览
水库运行态势
水情监控
发电统计
水位过程
负荷过程
预警信息
调度指令状态
```

页面应符合全局设计规范中的“智慧水利、数字流域、调度中心、科研分析平台、GIS系统、专业后台系统”风格要求，采用深色写实科技风、蓝青色高亮、卡片化布局和真实 GIS 质感。

------

## 3. 页面整体风格

首页整体采用：

```text
深色写实科技风
中国水利调度主题
智慧水库群调度系统风格
专业科研平台界面
16:9 宽屏布局
适配 1920×1080
```

视觉要求：

```text
1. 页面整体为深蓝色背景。
2. 面板采用深色半透明玻璃拟态。
3. 边框使用蓝青色细线。
4. 地图作为页面视觉中心。
5. 左右两侧为监控与分析面板。
6. 顶部为系统标题、导航栏和调度状态。
7. 底部为通知公告、天气与退出系统信息。
8. 不做过度霓虹、赛博朋克、游戏化或概念科幻风格。
```

颜色和面板样式应遵循全局规范中的主背景色、主色、强调色和半透明面板要求。

------

## 4. 页面整体布局

首页采用：

```text
顶部系统栏 + 三栏主体布局 + 底部状态栏
```

整体结构：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部系统栏：Logo / 系统名称 / 导航菜单 / 当前时间 / 调度状态  │
├───────────────┬──────────────────────────────┬───────────────┤
│ 左侧监控区     │ 中部 GIS 地图区               │ 右侧分析区     │
│ 水情监控       │ 黄河上游流域地图              │ 水位过程线     │
│ 发电统计       │ 水库点位 / 图层控制 / 工具栏  │ 负荷过程线     │
│               │                              │ 预警信息       │
├───────────────┴──────────────────────────────┴───────────────┤
│ 底部状态栏：通知公告 / 城市天气 / 退出系统                    │
└──────────────────────────────────────────────────────────────┘
```

布局比例建议：

```text
左侧监控区：约 30%
中部地图区：约 40%
右侧分析区：约 30%
```

页面主体不应做成密集数据大屏，应保持模块边界清晰、图表区完整、留白适中。

## 5. 顶部系统栏

### 5.1 区域位置

页面最顶部，横向贯穿全屏。

### 5.2 内容组成

顶部系统栏包含：

```text
1. 系统 Logo
2. 系统名称
3. 一级导航菜单
4. 当前时间
5. 调度指令状态
```

### 5.3 系统名称

显示：

```text
黄河上游水库群调度系统
```

要求：

```text
1. 位于左上角。
2. 字体较大，白色或浅蓝色。
3. 具有水利调度系统的专业感。
4. 左侧可保留抽象水滴/流域类 Logo，但不要使用卡通水滴图标。
```

### 5.4 顶部导航

导航菜单为：

```text
首页 / 水调水情 / 基础数据 / 模型配置 / 过程透明 / 评价决策 / 案例库 / 报表统计
```

说明：

```text
1. 当前页面“首页”高亮。
2. 导航采用横向按钮式布局。
3. 高亮颜色使用蓝青色。
4. 导航按钮可使用斜切边框或科技风细边框。
5. 原型图中为“数据管理”，当前项目统一建议使用“基础数据”。
```

### 5.5 调度指令状态

右上角展示：

```text
当前时间：2025-05-26 09:32:45
调度指令状态：● 正常执行
```

要求：

```text
1. 状态点使用绿色。
2. 状态文字使用绿色或浅绿色。
3. 表示系统当前调度指令处于正常执行状态。
4. 当前阶段为 mock 展示，不接真实调度状态。
5. 当前时间使用 mock 数据或前端实时格式化时间。
```

```text

出库流量
```


```text

预警：橙色
异常：红色
```

状态颜色应遵循全局数据状态体系。

## 6.1.6 布局要求

```text
1. 每座水库一个独立小面板。
2. 水库名称与状态标签位于顶部。
3. 指标采用 2 行或 3 行网格排列。
4. 每个指标显示名称、数值和单位。
5. 指标之间留有间距，避免拥挤。
6. 单位必须清晰显示。
```

## 11. 页面交互规则

## 11.1 导航交互

```text
1. 点击顶部导航可切换对应页面。
2. 当前页面首页高亮。
3. 导航切换由 Vue Router 控制。
```

## 11.2 地图交互

```text
1. 点击水库点位，打开水库信息窗。
2. 点击图层控制开关，切换 mock 图层显示状态。
3. 点击全域按钮，地图回到默认视图。
4. 点击缩放按钮，地图放大或缩小。
```

## 11.3 图表交互

```text
1. 水位过程线支持 tooltip。
2. 负荷过程线支持 tooltip。
3. 负荷过程线支持有功 / 无功切换。
4. 图例可点击控制对应折线显示隐藏。
```

## 11.4 预警交互
