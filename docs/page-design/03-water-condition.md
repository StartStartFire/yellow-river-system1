# 水调水情页面设计说明

## 1. 页面名称

```text
水调水情
```

## 2. 页面定位

水调水情页面用于展示水库调令执行过程下的水位、流量、出力等过程数据对比，重点体现“调令目标值”和“实际执行值”之间的过程变化关系，用于分析调度执行效果。

该页面是系统中的运行监测与过程分析页面，强调：

```text
调令执行对比
过程线分析
目标值与实际值对比
时间范围筛选
水库维度切换
水位 / 流量 / 出力三类指标切换
```

页面风格必须延续首页的深色智慧水利科研平台风格，采用深蓝背景、蓝青色高亮、半透明面板、专业科研分析系统视觉。

------

## 3. 页面开发目标

本页面当前阶段需要实现：

```text
1. 展示顶部系统栏和导航栏。
2. 当前导航“水调水情”高亮。
3. 展示顶部筛选区：时间范围、水库选择、查询、重置。
4. 展示指标切换页签：水位、流量、出力。
5. 默认展示“水位”页签。
6. 展示调令执行对比过程图。
7. 支持目标值与实际值两条过程线对比。
8. 支持更新时间节点标记。
9. 支持图表右上角单位切换下拉、下载、全屏按钮 UI。
10. 页面整体保持简洁，不堆叠过多图表。
```

当前阶段不实现：

```text
1. 不调用后端接口。
2. 不连接数据库。
3. 不调用 MATLAB。
4. 不做真实数据查询。
5. 不做真实导出下载。
6. 不做真实全屏业务逻辑。
7. 不做复杂联动分析。
```

## 4. 页面整体布局

页面采用：

```text
顶部系统栏 + 顶部筛选区 + 指标页签区 + 核心过程图卡片
```

页面结构如下：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部系统栏：系统名称 / 面包屑 / 当前时间 / 状态   │
├──────────────────────────────────────────────────────────────┤
│ 顶部筛选区：时间范围 / 水库选择 / 查询 / 重置               │
├──────────────────────────────────────────────────────────────┤
│ 指标页签区：水位 / 流量 / 出力                               │
├──────────────────────────────────────────────────────────────┤
│ 图表卡片：标题 + 单位切换 + 下载 + 全屏                     │
│                                                          │
│                调令执行对比过程图                         │
│                                                          │
│                图例：目标值 / 实际值                      │
└──────────────────────────────────────────────────────────────┘
```

布局要求：

```text
1. 页面主体保持大面积单图分析结构。
2. 不要在同一屏铺满多张小图。
3. 图表是页面核心主体，需占据主要面积。
4. 顶部筛选区高度适中，保持清晰简洁。
5. 页签区与图表区层级清晰。
```


```text

4. 图标可分别对应折线、水波、闪电等语义。
5. 风格需与首页和其他模块保持一致。
```

```text

```

要求：

```text

2. 标记文本放置在线附近。

```

在两条线的最右端显示数值标签：

```text

实际 2467.35
```

要求：

```text
1. 标签颜色与对应曲线一致。
2. 标签位于曲线末端右侧。
3. 数值保留两位小数。
```

## 9.7 图表视觉要求

```text
1. 目标值曲线使用亮蓝色虚线或点线。
2. 实际值曲线使用青绿色实线。
3. 数据点采用圆点标记。
4. 图表背景透明。
5. 网格线使用低透明度虚线。
6. tooltip 必须可用。
7. legend 位于图表底部居中。
8. 坐标轴与文字适配深色主题。
9. 右下角显示单位：m。
```
