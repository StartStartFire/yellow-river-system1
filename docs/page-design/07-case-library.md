# 案例库页面设计说明

## 1. 页面名称

```text
案例库
```

## 2. 页面定位

案例库页面用于对历史调度案例进行集中管理、检索、查看、对比和复现。

该页面既是历史案例沉淀页面，也是模型复现与经验参考页面，主要承担以下作用：

```text
1. 展示历史调度案例列表。
2. 支持按时间、案例类型、水库、关键词进行筛选。
3. 支持查看案例详情。
4. 支持查看案例配置摘要、历史结果摘要、过程预览和评价结论。
5. 支持收藏、导出报告、对比分析和复现案例。
```

页面风格必须延续首页的深色智慧水利科研平台风格，采用深蓝背景、蓝青色高亮、半透明面板、专业科研分析系统视觉。

------

## 3. 页面开发目标

本页面当前阶段需要实现：

```text
1. 展示顶部系统栏和导航栏。
2. 当前导航“案例库”高亮。
3. 展示顶部筛选区。
4. 支持时间范围、案例类型、涉及水库、关键词筛选。
5. 支持查询、重置、高级筛选按钮。
6. 左侧展示案例列表。
7. 右侧展示当前选中案例的详情。
8. 支持详情区页签切换。
9. 展示关键指标卡片。
10. 展示过程曲线预览。
11. 支持收藏、导出报告、更多操作按钮。
12. 支持查看详细报告、对比分析、复现案例按钮。
```

当前阶段不实现：

```text
1. 不调用后端接口。
2. 不连接数据库。
3. 不调用 MATLAB。
4. 不做真实案例检索。
5. 不做真实收藏同步。
6. 不做真实报告导出。
7. 不做真实案例复现。
8. 不做真实案例对比计算。
```

## 4. 页面整体布局

案例库页面采用：

```text
顶部系统栏 + 顶部筛选区 + 左侧案例列表区 + 右侧案例详情区
```

页面结构如下：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部系统栏：系统名称 / 导航菜单 / 当前时间  / 状态 │
├──────────────────────────────────────────────────────────────┤
│ 顶部筛选区：时间范围 / 案例类型 / 涉及水库 / 关键词 / 按钮   │
├───────────────────────────────────────┬──────────────────────┤
│ 案例列表                               │ 案例详情              │
│ 缩略图 + 标题 + 基本信息 + 状态         │ 标题 + 状态 + 按钮    │
│ 多个案例卡片纵向排列                    │ 页签内容              │
│                                        │ 关键指标              │
│                                        │ 过程曲线预览          │
│                                        │ 底部操作按钮          │
└───────────────────────────────────────┴──────────────────────┘
```

布局要求：

```text
1. 页面采用左右双栏布局。
2. 左侧为案例列表，右侧为详情展示。
3. 左侧宽度约 50%~52%，右侧宽度约 48%~50%。
4. 顶部筛选区独立成块。
5. 右侧详情区信息分层清晰，不做过度拥挤布局。
6. 页面保持科研平台风格，不做轻量浅色后台风格。
```
