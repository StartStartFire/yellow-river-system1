# 评价决策页面设计说明

## 1. 页面名称

```text
评价决策
```

## 2. 页面定位

评价决策页面用于展示模型计算完成后的多方案评价分析和单方案决策分析结果。

页面分为两个核心卡片：

```text
评价分析
决策分析
```

其中：

```text
评价分析：用于多方案对比，展示雷达图、评价指标流向图、帕累托曲线和评价算法排名分析。
决策分析：用于单方案深入分析，展示目标满足情况、过程曲线、水量使用流向图，并提供导出方案入口。
```

当前阶段只开发前端页面原型，不调用后端接口，不连接数据库，不调用 MATLAB，不实现真实评价算法计算和真实导出。页面数据全部来自：

```text
src/mock/evaluationDecision.ts
```

页面风格必须延续首页的深色智慧水利科研平台风格，采用深蓝背景、蓝青色高亮、半透明面板、专业科研分析系统视觉。全局页面规范要求系统保持智慧水利、数字流域、调度中心、科研分析平台、专业后台系统等视觉特征。

------

## 3. 页面开发目标

本页面当前阶段需要实现：

```text
1. 展示顶部系统栏和导航栏。
2. 当前导航“评价决策”高亮。
3. 展示“评价分析”折叠卡片。
4. 展示“决策分析”折叠卡片。
5. 默认展开评价分析，默认折叠决策分析。
6. 评价分析支持多方案对比选择。
7. 评价分析展示雷达图、评价指标图、帕累托曲线、评价算法排名分析。
8. 决策分析支持单方案选择。
9. 决策分析展示目标满足情况、过程曲线、水量使用流向图。
10. 决策分析右上角展示“导出方案”按钮。
11. 支持展开 / 折叠评价分析和决策分析。
12. 所有图表使用 mock 数据渲染。
```

当前阶段不实现：

```text
1. 不调用后端接口。
2. 不连接数据库。
3. 不调用 MATLAB。
4. 不做真实评价算法计算。
5. 不做真实方案排序计算。
6. 不做真实方案导出。
7. 不写入案例库。
8. 不做真实 Excel / PDF 导出。
```

## 4. 页面整体布局

评价决策页面采用：

```text
顶部系统栏 + 评价分析折叠卡片 + 决策分析折叠卡片
```

页面结构如下：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部系统栏：系统名称 / 导航菜单 / 当前时间 / 状态 │
├──────────────────────────────────────────────────────────────┤
│ 评价分析卡片                                                  │
│ 多方案对比选择                                                │
│ 雷达图                  | 多方案评价指标图                    │
│ 帕累托曲线              | 评价算法排名分析                    │
├──────────────────────────────────────────────────────────────┤
│ 决策分析卡片                                                  │
│ 当前决策方案 / 导出方案                                       │
│ 目标满足情况        | 过程曲线             | 水量使用流向图   │
└──────────────────────────────────────────────────────────────┘
```

默认状态：

```text
评价分析：展开
决策分析：折叠
```

用户可手动折叠评价分析并展开决策分析。

评价分析卡片用于展示多个调度方案之间的综合评价对比结果。

```text
展开
```

卡片标题：

```text
评价分析
```

右侧显示折叠箭头。

## 6.2 顶部控件：多方案对比选择

评价分析卡片顶部显示：

```text
多方案对比：
方案一 / 方案二 / 方案三 / 方案四
```

控件形式：

```text
复选框组
```

默认选中：

```text
方案一
方案二
方案三
```

方案四默认不选中。

交互要求：

```text
1. 用户可勾选参与评价对比的方案。
2. 至少选择一个方案。
3. 勾选变化后，雷达图、评价指标图、帕累托曲线、排名分析同步更新 mock 数据。
4. 当前阶段只做前端状态切换。
```

## 7. 评价分析图表区

评价分析图表区由上下两层组成：

```text
第一层：多方案评价雷达图 + 多方案评价指标图
第二层：帕累托曲线 + 评价算法排名分析
```

整体要求：

```text
1. 图表区域分块清晰。
2. 不允许图表重叠。
3. 不做过密数据大屏。
4. 每个图表必须有标题。
5. 每个图表必须适配深色主题。
6. 图表数据来自 src/mock/evaluationDecision.ts。
```

图表应遵循全局 ECharts 图表规范，包含标题、单位、图例和 tooltip。

# 9.1 目标满足情况

## 标题



每个目标项包含：

```text

2. 目标名称
3. 满足状态
4. 完成率进度条

```

## 示例

```text
发电目标      已满足      96.5%
生态目标      已满足      93.2%
灌溉目标      基本满足    82.4%
```

```text
已满足：绿色
基本满足：黄色 / 橙色
未满足：红色
```

## 底部说明

显示：

```text
完成率 = 实际值 / 目标值 × 100%
```

## 11. 页面交互规则

### 11.1 评价分析折叠

```text
1. 默认展开评价分析。
2. 点击右侧箭头可折叠评价分析。
3. 折叠后只显示标题栏。
4. 当前阶段只做前端状态切换。
```

### 11.2 决策分析折叠

```text
1. 默认折叠决策分析。
2. 点击右侧箭头可展开决策分析。
3. 展开后展示目标满足情况、过程曲线、水量使用流向图。
4. 当前阶段只做前端状态切换。
```

### 11.3 多方案对比选择

```text
1. 默认选中方案一、方案二、方案三。
2. 用户可勾选方案四。
3. 至少保留一个方案。
4. 勾选后雷达图、评价指标图、帕累托曲线、排名分析同步更新。
5. 当前阶段只切换 mock 数据。
```

### 11.4 单方案选择

```text
1. 决策分析默认选中方案二。
2. 切换当前决策方案后，目标满足情况、过程曲线、水量流向图同步更新。
3. 当前阶段只切换 mock 数据。
```

### 11.5 过程曲线页签

```text
1. 默认显示水位变化。
2. 点击流量变化，切换为流量过程线。
3. 点击出力变化，切换为出力过程线。
4. 图表标题、单位、图例同步变化。
```

### 11.6 导出方案

```text
1. 点击导出方案按钮，当前阶段只弹出提示。
2. 不生成真实文件。
3. 不调用后端接口。
```
