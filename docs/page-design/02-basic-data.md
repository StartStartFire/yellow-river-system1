# 基础数据页面设计说明

## 1. 页面名称

```text
基础数据
```

## 2. 页面定位

基础数据页面用于以水库对象为核心，展示水库静态信息、关键运行指标、水库断面、水情过程和工情信息。

当前阶段只做前端页面原型展示，不接后端接口，不连接数据库，不实现真实数据查询和修改。页面数据全部来自：

```text
src/mock/basicData.ts
```

基础数据页面应延续首页的导航栏、深色科技风、蓝青色高亮、半透明面板和专业水利科研平台视觉风格。整体风格应符合全局规范中的“智慧水利、数字流域、调度中心、科研分析平台、GIS系统、专业后台系统”要求。

------

## 3. 页面整体风格

页面采用：

```text
深色写实科技风
中国智慧水利科研平台风格
蓝青色高亮
专业后台系统风格
16:9 宽屏布局
适配 1920×1080
```

视觉要求：

```text
1. 顶部导航栏与首页保持一致。
2. 当前导航“基础数据”高亮。
3. 页面整体为深蓝色背景。
4. 页面主体使用深色半透明卡片。
5. 卡片边框使用蓝青色细线。
6. 重点数值使用白色或浅蓝色突出。
7. 变化值可使用绿色、橙色等状态色。
8. 页面不做密集数据大屏，信息分区清晰。
```

面板和卡片样式应遵循全局规范中的深色半透明面板、轻玻璃拟态、蓝色边框和柔和阴影要求。

------

## 4. 页面整体布局

基础数据页面采用：

```text
顶部系统栏 + 左侧水库列表 + 右侧水库详情区
```

整体结构：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部系统栏：系统名称 / 导航菜单 / 当前时间 / 调度令状态 │
├───────────────┬──────────────────────────────────────────────┤
│ 左侧水库列表   │ 右侧水库详情区                               │
│               │ 顶部：水库信息页签                           │
│ 龙羊峡         │ 水库名称                                     │
│ 刘家峡         │ 核心指标卡片                                 │
│               │ 标签页：基础信息 / 水库断面 / 水情过程 / 工情信息 │
│               │ 当前标签内容区                               │
└───────────────┴──────────────────────────────────────────────┘
```

布局比例建议：

```text
左侧水库列表：约 18% - 20%
右侧详情区：约 80% - 82%
```

页面主体高度应尽量贴合一屏展示，避免出现大量纵向滚动。

# 8.2 水库断面标签页

## 8.2.1 功能定位

水库断面用于以示意图方式展示水库坝体、库区水位、特征水位、当前水位、入库流量和出库流量。

当前原型图重点展示此标签页。

## 8.2.2 内容标题

显示：

```text
龙羊峡水库断面示意图
```

切换水库后标题同步变化：

```text
刘家峡水库断面示意图
```

## 8.2.3 断面图主体元素

断面图包括：

```text
1. 左侧高程坐标轴
2. 山体剖面
3. 水体填充区域
4. 大坝结构
5. 特征水位水平线
6. 当前水位高亮线
7. 入库流量箭头
8. 出库流量箭头
9. 坝顶高程标注
10. 底部工程参数说明栏
```

## 8.2.4 高程坐标轴

左侧显示：

```text
高程（m）
```

刻度示例：

```text
2520
2500
2480
2460
2440
2420
2400
2380
```

要求：

```text
1. 坐标轴颜色使用浅灰蓝。
2. 刻度文字清晰可读。
3. 不需要完全等比例工程制图，但视觉上应符合水库断面认知。
```

## 8.2.5 特征水位线

断面图中需要展示以下水位：

```text
校核洪水位
设计洪水位
正常蓄水位
汛限水位
当前水位
死水位
```

示例数据：

```text
校核洪水位：2505.00 m
设计洪水位：2497.00 m
正常蓄水位：2480.00 m
汛限水位：2470.00 m
当前水位：2467.35 m
死水位：2410.00 m
```

展示要求：

```text
1. 每条水位线使用不同颜色虚线或细线。
2. 左侧显示水位名称。
3. 右侧或线尾显示具体高程值。
4. 当前水位使用蓝色实线或蓝色高亮条突出显示。
5. 当前水位可在水体边界处显示明显标签。
```

## 8.2.6 水体和山体

```text
1. 水体区域使用蓝色半透明渐变填充。
2. 水体上边界与当前水位保持一致。
3. 山体剖面使用深色纹理或渐变背景。
4. 整体应接近原型图中的真实断面视觉。
```

## 8.2.7 大坝结构

大坝位于断面图右侧。

展示要求：

```text
1. 使用灰色坝体材质。
2. 表现重力坝或混凝土坝形态。
3. 坝顶显示坝顶高程。
4. 坝体不需要真实三维建模，但应具有工程示意感。
```

坝顶高程示例：

```text
坝顶高程：2510.00 m
```

## 8.2.8 入库流量与出库流量

断面图右侧显示：

```text
当前入库流量：487.6 m³/s
当前出库流量：612.3 m³/s
```

展示要求：

```text
1. 入库流量箭头指向库区。
2. 出库流量箭头从坝体方向流出。
3. 箭头使用蓝色高亮。
4. 文案与数值靠近箭头显示。
```

## 8.2.9 底部工程参数栏

断面图底部显示工程参数。

字段包括：

```text
坝型
坝顶高程
坝顶长度
最大坝高
```

示例：

```text
坝型：混凝土重力坝
坝顶高程：2510.00 m
坝顶长度：393.00 m
最大坝高：178.00 m
```

样式要求：

```text
1. 使用横向信息条。
2. 背景为深色半透明。
3. 左侧可带信息图标。
4. 字段之间留有足够间距。
```
