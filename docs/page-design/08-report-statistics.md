# 报表统计页面设计说明

## 1. 页面名称

```text
报表统计
```

## 2. 页面定位

报表统计页面用于集中展示水库调度运行统计结果、经济指标、发电量及发电考核情况，支持按逐月报表、逐年报表进行查看，并提供查询、重置和导出报表入口。

该页面面向科研汇报、成果归档和运行统计分析场景，强调：

```text
1. 报表结构清晰。
2. 多级表头真实。
3. 水库运行指标完整。
4. 逐月、逐年统计口径明确。
5. 支持 Excel 导出入口。
```

页面风格必须延续首页的深色智慧水利科研平台风格，采用深蓝背景、蓝青色高亮、半透明面板、专业科研分析系统视觉。

------

## 3. 页面开发目标

本页面当前阶段需要实现：

```text
1. 展示顶部系统栏和导航栏。
2. 当前导航“报表统计”高亮。
3. 展示顶部筛选区。
4. 支持报表类型切换：逐月报表 / 逐年报表。
5. 支持年份、月份、水库筛选。
6. 支持查询、重置、导出报表按钮。
7. 展示逐月报表三个表块：
   - 水库调度运行情况
   - 水库运行主要经济指标
   - 发电量及发电考核情况
8. 支持逐年报表切换展示。
9. 表格支持多级表头、单位展示和深色主题。
```

当前阶段不实现：

```text
1. 不调用后端接口。
2. 不连接数据库。
3. 不做真实统计计算。
4. 不做真实 Excel 导出。
5. 不做真实打印。
6. 不做复杂权限控制。
```

------

## 4. 页面整体布局

报表统计页面采用：

```text
顶部系统栏 + 顶部筛选操作区 + 报表表格展示区
```

页面结构如下：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部系统栏：系统名称 / 导航菜单 / 当前时间  / 状态 │
├──────────────────────────────────────────────────────────────┤
│ 筛选操作区：报表类型 / 年份 / 月份 / 水库筛选 / 查询 / 重置 / 导出 │
├──────────────────────────────────────────────────────────────┤
│ 一、水库调度运行情况                                          │
│ 多级表头统计表                                                │
├──────────────────────────────────────────────────────────────┤
│ 二、水库运行主要经济指标                                      │
│ 多级表头统计表                                                │
├──────────────────────────────────────────────────────────────┤
│ 三、发电量及发电考核情况                                      │
│ 多级表头统计表                                                │
├──────────────────────────────────────────────────────────────┤
│ 底部说明文字                                                  │
└──────────────────────────────────────────────────────────────┘
```

布局要求：

```text
1. 页面以表格为主体。
2. 顶部筛选区固定在表格上方。
3. 表格分为多个报表块。
4. 每个报表块标题清晰。
5. 表格使用多级表头。
6. 表格内容尽量在一屏内展示，必要时支持横向滚动。
7. 不要添加过多图表，避免弱化报表属性。
```

# 7. 逐月报表内容

逐月报表默认展示三个表块：

```text
一、水库调度运行情况
二、水库运行主要经济指标
三、发电量及发电考核情况
```

------

## 7.1 表块一：水库调度运行情况

### 7.1.1 表块标题

```text
一、水库调度运行情况
```

### 7.1.2 表格字段

表格采用多级表头。

一级字段包括：

```text
水库名称
水位（m）
库容（亿m³）
入库水量（亿m³）
出库水量（亿m³）
弃水量（亿m³）
```

二级字段如下：

```text
水位（m）：
- 期初水位
- 期末水位
- 最高水位
- 最低水位

库容（亿m³）：
- 期初库容
- 期末库容
- 最大库容
- 最小库容

入库水量（亿m³）：
- 本月
- 年累计

出库水量（亿m³）：
- 总出库：本月 / 年累计
- 发电放水：本月 / 年累计
- 下泄生态水量：本月 / 年累计

弃水量（亿m³）：
- 本月
- 年累计
```

### 7.1.3 表格行

建议展示：

```text
龙羊峡水库
刘家峡水库
青铜峡水库
玛尔挡水库
拉西瓦水库
合计
```

### 7.1.4 展示要求

```text
1. 多级表头必须清晰。
2. 单位写在表头中。
3. 合计行位于表格底部。
4. 表格边框使用低透明度蓝色线条。
5. 表格字体清晰，不要过小。
```

## 11. 页面交互规则

```text

2. 点击“逐年报表”后切换为年度汇总表。
3. 逐年报表下月份选择隐藏或禁用。
```

```text
1. 用户选择年份、月份、水库后点击查询。

3. 不调用后端接口。
```

```text
1. 点击重置恢复默认条件。
2. 默认条件为：逐月报表、2025年、5月、全部水库。
```

```text
1. 点击导出报表按钮，当前阶段只弹出提示。
2. 提示文案：当前为前端原型，暂不支持真实导出。
3. 不生成真实 Excel。
4. 不触发真实下载。
```

### 11.5 表格滚动

```text
1. 表格列较多时允许横向滚动。
```
