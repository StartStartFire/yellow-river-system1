# 模型配置 Step 2：基础配置页面设计说明

## 1. 页面名称

```text
基础配置
```

## 2. 所属模块

```text
模型配置 / Step 2：基础配置
```

## 3. 页面定位

基础配置页面是模型配置流程的第二步，用于设置本次调度计算的基础信息，包括调度周期、方案名称、水库组合、调度目标和约束条件摘要。

本页面应延续首页和模型数据页面的深色科技风、蓝青色高亮、半透明面板和专业水利科研平台风格。

------

## 4. 页面开发目标

本页面当前阶段需要实现：

```text
1. 展示模型配置顶部五步流程。
2. 高亮当前步骤“基础配置”。
3. 展示调度周期设置区域。
4. 展示方案名称输入区域。
5. 展示水库组合选择区域。
6. 展示调度目标设置区域。
7. 展示约束条件设置摘要区域。
8. 支持取消、保存、下一步操作。
9. 点击“下一步”进入 Step 3：模型算法页面。
```

当前阶段不实现：

```text
1. 不调用后端接口。
2. 不连接数据库。
3. 不调用 MATLAB。
4. 不做真实参数校验。
5. 不做真实约束冲突判断。
6. 不做真实任务保存。
```

------

## 5. 页面整体布局

基础配置页面采用：

```text
顶部系统栏 + 模型配置五步流程条 + 基础配置内容区 + 底部操作栏
```

页面结构如下：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部系统栏：系统名称 / 导航菜单 / 当前时间 / 状态 │
├──────────────────────────────────────────────────────────────┤
│ 模型配置五步流程：模型数据 → 基础配置 → 模型算法 → 场景约束 → 配置汇总 │
├──────────────────────────────────────────────────────────────┤
│ 内容区第一行：调度周期设置        | 方案名称                  │
├──────────────────────────────────────────────────────────────┤
│ 内容区第二行：水库组合选择                                      │
├──────────────────────────────────────────────────────────────┤
│ 内容区第三行：调度目标设置        | 约束条件设置              │
├──────────────────────────────────────────────────────────────┤
│ 底部操作栏：取消 / 保存 / 下一步                              │
└──────────────────────────────────────────────────────────────┘
```

布局要求：

```text
1. 页面主体保持一屏展示。
2. 信息分区清晰，不做密集数据大屏。
3. 内容区采用卡片化布局。
4. 卡片之间保持合理间距。
5. 底部操作栏与上一页模型数据页面保持一致。
```

## 7. 模型配置五步流程条

## 7.1 正确步骤内容

本项目统一使用 5 个步骤：

```text
1 模型数据
2 基础配置
3 模型算法
4 场景约束
5 配置汇总
```

每个步骤说明为：

```text
模型数据：选择与管理模型输入数据
基础配置：设置调度规则与工程目标
模型算法：选择模型与优化算法
场景约束：布置调度场景与约束条件
配置汇总：确认配置并开始计算
```

## 7.2 当前步骤状态

当前页面为第二步：

```text
基础配置
```

展示要求：

```text
1. “2 基础配置”高亮显示。
2. 步骤编号使用圆形数字。
3. 步骤之间使用箭头或连接线表达流程关系。
4. 样式与 Step 1 模型数据页面保持一致。
```

## 7.3 交互规则

```text
1. 点击已完成的 Step 1 可返回模型数据页面。
2. 当前 Step 2 保持高亮。
3. 未完成步骤当前阶段可不允许直接跳转。
4. 点击底部“下一步”进入 Step 3：模型算法。
5. 步骤切换只做前端路由跳转或前端状态切换。
```

推荐路由：

```text
/model-config/model-data
/model-config/basic-config
/model-config/model-algorithm
/model-config/scenario-constraint
/model-config/config-summary
```

## 8. 内容区一：调度周期设置

## 8.1 区域标题

标题显示：

```text
1. 调度周期设置
```

标题左侧可使用时钟类图标。

## 8.2 区域位置

位于内容区第一行左侧。

## 8.3 字段内容

包含以下字段：

```text
开始时间
结束时间
时间步长
调度频率
总时段数
```

### 开始时间

示例：

```text
2025-05-16
```

控件类型：

```text
Element Plus 日期选择器
```

### 结束时间

示例：

```text
2025-05-26
```

控件类型：

```text
Element Plus 日期选择器
```

### 时间步长

示例：

```text
每天
```

控件类型：

```text
下拉选择框
```

可选值：

```text
每日
每旬
每月
```

### 调度频率

示例：

```text
每月一次
```

控件类型：

```text
下拉选择框
```

可选值：

```text
每周一次
每月一次
按需调度
```

### 总时段数

示例：

```text
总时段数：241 个时段
```

展示要求：

```text
1. 总时段数根据开始时间、结束时间、时间步长自动计算。
2. 当前阶段可使用 mock 计算或写死展示。
3. 文字位于卡片右下角。
```

## 8.4 布局要求

```text
1. 字段采用两列布局。
2. 开始时间和结束时间在第一行。
3. 时间步长和调度频率在第二行。
4. 总时段数显示在卡片底部右侧。
5. 输入框、下拉框必须适配深色主题。
```


每个组合卡片包含：


示例：

```text

- 龙羊峡水库
```

```
- 龙羊峡水库
- 刘家峡水库
- 黑山峡水库
```

## 10.6 交互规则

```text
1. 水库组合为单选。
2. 默认选中“龙刘组合”。
3. 点击其他组合后，取消原组合选中状态。
4. 当前选中组合使用蓝色高亮边框和角标。
5. 未选中组合使用低亮度边框。
6. 当前阶段只保存前端状态，不调用接口。
```

## 10.7 布局要求

```text
1. 组合卡片横向排列。
2. 一行展示多个组合卡片。
3. 卡片高度保持一致。
4. 选中卡片应明显突出。
```

```text
1. 如果项目还没有公共组件，可以先在 BasicConfigView.vue 中完成页面。
2. 页面稳定后再拆分组件。
3. 不要因为开发基础配置页面而重构其他页面。

```

## 17. 页面验收标准

基础配置页面完成后应满足：

```text
1. 页面可以通过 /model-config/basic-config 正常访问。
2. 顶部导航完整显示。
3. 当前导航“模型配置”高亮。
4. 顶部五步流程完整显示。
5. 当前步骤“基础配置”高亮。
6. Step 1“模型数据”显示为已完成状态。
7. 页面不使用原型图中的 4 步流程，应使用统一 5 步流程。
8. 调度周期设置区域正常显示。
9. 方案名称输入框正常显示。
10. 水库组合选择卡片正常显示。
11. 默认选中“龙刘组合”。
12. 调度目标卡片正常显示。
13. 默认选中“防洪安全”。
14. 约束条件设置摘要正常显示。
15. 点击“查看详情”可展示 mock 约束列表。
16. 底部显示取消、保存、下一步按钮。
17. 点击保存有前端提示。
18. 点击下一步可以进入模型算法页面。
19. 页面数据全部来自 src/mock/modelConfig.ts。
20. 不调用后端接口。
21. 不连接数据库。
22. 不调用 MATLAB。
```
