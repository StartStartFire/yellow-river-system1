# 模型配置 Step 2：基础配置页面设计说明

## 1. 页面名称

```text
基础配置
```

## 2. 所属模块

```text
模型配置 / Step 2：基础配置
```

## 3. 页面定位

基础配置页面是模型配置流程的第二步，用于设置本次调度计算的基础信息，包括调度周期、方案名称、水库组合、调度目标和约束条件设置。

本页面应延续首页和模型数据页面的深色科技风、蓝青色高亮、半透明面板和专业水利科研平台风格。

------

## 4. 页面开发目标

本页面当前阶段需要实现：

```text
1. 展示模型配置顶部五步流程。
2. 高亮当前步骤"基础配置"。
3. 展示调度周期设置区域。
4. 展示方案名称输入区域。
5. 展示水库组合选择区域。
6. 展示调度目标设置区域。
7. 展示约束条件设置区域（弹窗中可编辑开关）。
8. 支持取消、保存、下一步操作。
9. 点击"下一步"进入 Step 3：模型算法页面。
```

当前阶段不实现：

```text
1. 不调用后端接口。
2. 不连接数据库。
3. 不调用 MATLAB。
4. 不做真实参数校验。
5. 不做真实约束冲突判断。
6. 不做真实任务保存。
```

------

## 5. 页面整体布局

基础配置页面采用：

```text
顶部系统栏 + 模型配置五步流程条 + 基础配置内容区 + 底部操作栏（公用组件）
```

页面结构如下：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部系统栏：系统名称 / 导航菜单 / 当前时间 / 状态 │
├──────────────────────────────────────────────────────────────┤
│ 模型配置五步流程：模型数据 → 基础配置 → 模型算法 → 场景配置 → 配置汇总 │
├──────────────────────────────────────────────────────────────┤
│ Row 1：调度周期设置（独占一行，总时段数显示在标题栏最右侧）    │
├──────────────────────────────────────────────────────────────┤
│ Row 2：方案名称（独占一行，高度缩减，输入框+字数计数）         │
├──────────────────────────────────────────────────────────────┤
│ Row 3：水库组合选择              | 约束条件设置（可编辑弹窗） │
├──────────────────────────────────────────────────────────────┤
│ Row 4：调度目标设置（独占一行，5 列网格布局）                 │
├──────────────────────────────────────────────────────────────┤
│ 底部操作栏（ModelConfigFooter）：取消 / 上一步 / 保存 / 下一步 │
└──────────────────────────────────────────────────────────────┘

## 11. 内容区四：调度目标设置

### 11.1 区域标题

```text
5. 调度目标设置
```

### 11.2 调度目标选项

当前支持以下 5 个调度目标：

```text

兴利发电
生态保护
输沙调度

```

### 11.3 展示形式

采用 5 列等宽网格布局（grid-template-columns: repeat(5, 1fr)），每个目标一个卡片，包含图标、名称、描述和选中勾选标记。

### 11.4 联动关系

```text
选定调度目标后，Step 4（场景配置）中相关参数会高亮显示。
关联规则定义在 objectiveRelevantParams：
  · 生态保护 → 下游生态流量、冲沙流量要求
  · 输沙调度 → 调沙流量、冲沙流量要求
  · 防洪安全 / 兴利发电 / 多能互补 → 无关联参数
```

## 12. 内容区五：约束条件设置（可编辑）

### 12.1 区域标题

标题显示：

```text
4. 约束条件设置
```

### 12.2 展示内容

约束条件区域显示约束配置摘要：

```text
已配置 N 项约束条件
约束条件将影响调度方案的可行性与优化结果
```

右侧按钮：

```text
查看详情
```

### 12.3 交互规则

```text
1. 点击"查看详情"打开约束编辑弹窗。
2. 弹窗中每项约束前面有 el-switch 开关，默认全部开启。
3. 用户可开启/关闭某些约束条件参与计算。
4. 弹窗标题为"选择本次计算需要启用的约束条件："。
5. 当前阶段不做真实冲突校验。
```

### 12.4 约束列表

```text
水位上限约束
水位下限约束
汛限水位约束
最小生态流量约束
最大发电出力约束
最小下泄流量约束
冲沙流量约束
库容边界约束
入库流量边界约束
出库流量边界约束
水量平衡约束
梯级协同约束
```

### 12.5 开关状态保存

约束开关状态通过以下方式管理：

```text
1. 页面内使用 constraintEnabled 响应式数组。
2. 保存时写入 Pinia store 的 basicConfig.constraintEnabled。
3. 供后续步骤和配置摘要读取。
```

## 13. 步骤间联动说明

本页面位于 Step 1 和 Step 3 之间，承担双向联动角色：

### 13.1 从 Step 1 接收数据

```text
进入页面时（onMounted）从 Store 读取 Step 1 传入的起止时间，自动填入调度周期。
用户也可手动修改起止时间。
```

### 13.2 向 Step 3 传递数据

```text
水库组合选择：
  → 联动 Step 3 模型筛选（不兼容模型自动隐藏并切换）
  → 调用 store.ensureCompatibleModelOnGroupChange()

时间步长选择：
  → 联动 Step 3 算法参数建议
  → 点击"下一步"时调用 store.applyTimeStepToAlgorithmParams()

调度目标选择：
  → 联动 Step 4 场景参数高亮
  → Step 4 页面读取 store.relevantScenarioParamIds
```

### 13.3 数据写入时机

```text
保存按钮：写入 Store（调用 store.setBasicConfig()）
下一步按钮：先写入 Store，再跳转
取消按钮：不写入 Store，弹出确认弹窗。确认后清除方案名称，以 toast 提示"已取消，未保存任何更改"，停留在当前页面不跳转。
```
