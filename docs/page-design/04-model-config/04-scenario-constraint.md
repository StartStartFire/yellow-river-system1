# 模型配置 Step 4：场景约束页面设计说明

## 1. 页面名称

```text
场景约束
```

## 2. 所属模块

```text
模型配置 / Step 4：场景约束
```

## 3. 页面定位

场景约束页面是模型配置流程的第四步，用于配置本次调度计算所采用的业务场景、调水条件、冲沙流量、工程运行状态、生态流量要求。

**设计变更**：约束条件配置已移至 Step 2 弹窗中编辑，Step 4 不再展示约束条件卡片，场景参数卡片改为全宽。

本页面应延续首页、模型数据、基础配置、模型算法页面的深色智慧水利科研平台风格，保持深色写实科技风、蓝青色高亮、半透明面板、专业后台系统视觉。

------

## 4. 页面开发目标

本页面当前阶段需要实现：

```text
1. 展示模型配置顶部五步流程。
2. 高亮当前步骤"场景约束"。
3. 展示场景配置区域。
4. 支持"典型场景 / 自定义场景"切换。
5. 展示场景描述输入区。
6. 展示场景参数配置区（全宽，无约束卡片）。
7. 支持取消、保存、下一步操作（使用 ModelConfigFooter 公用组件）。
8. 点击"下一步"进入 Step 5：配置汇总页面。
```

当前阶段不实现：

```text
1. 不调用后端接口。
2. 不连接数据库。
3. 不调用 MATLAB。
4. 不做真实约束冲突校验。
5. 不做真实场景计算。
6. 不做真实参数入库。
7. 不生成真实计算任务。
```

------

## 5. 页面整体布局

场景约束页面采用：

```text
顶部系统栏 + 模型配置五步流程条 + 场景配置内容区 + 底部操作栏（公用组件）
```

页面结构如下：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部系统栏：系统名称 / 导航菜单 / 当前时间  / 状态 │
├──────────────────────────────────────────────────────────────┤
│ 模型配置五步流程：模型数据 → 基础配置 → 模型算法 → 场景约束 → 配置汇总 │
├──────────────────────────────────────────────────────────────┤
│ 场景配置标题区                                                 │
│ 典型场景 / 自定义场景 切换                                     │
├──────────────────────────────────────────────────────────────┤
│ 场景描述                                                       │
├──────────────────────────────────────────────────────────────┤
│ 场景参数配置（全宽，无约束卡片）                                │
├──────────────────────────────────────────────────────────────┤
│ 底部操作栏（ModelConfigFooter）：取消 / 上一步 / 保存 / 下一步  │
└──────────────────────────────────────────────────────────────┘
```

布局要求：

```text
1. 页面主体保持一屏展示。
2. 上方为场景模式选择和场景描述。
3. 下方为场景参数配置（全宽）。
4. 不再展示约束条件卡片（已移至 Step 2）。
5. 页面整体不做密集数据大屏。
6. 卡片之间留出清晰间距。
```

## 6. 场景参数配置区（全宽）

### 6.1 区域标题

标题显示：

```text
场景参数配置
```

### 6.2 区域位置

位于页面下半部分，全宽。

### 6.3 参数列表

场景参数采用表单列表形式展示，每行一个参数。

包含以下参数：

```text
西线调水
调沙流量
骨干工程运行状态
冲沙流量要求
下游生态流量
```

每个参数通过下拉选择框配置，修改后保存到 Pinia store。

（各参数详细说明与原有设计一致，略）

### 6.4 步骤间联动说明

本页面与 Step 2（基础配置）的调度目标选择联动：

```text
调度目标 → 场景参数高亮：
  · 选择"防洪安全" → 骨干工程运行状态、调沙流量 高亮标记
  · 选择"兴利发电" → 骨干工程运行状态 高亮标记
  · 选择"生态保护" → 下游生态流量、冲沙流量要求 高亮标记

视觉反馈：
  · 关联参数显示蓝色边框和"关联"标签
  · 页面顶部显示当前调度目标名称提示
```

关联规则定义在 `src/mock/modelConfig.ts` 的 `objectiveRelevantParams` 中。
