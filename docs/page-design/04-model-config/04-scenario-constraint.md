# 模型配置 Step 4：场景约束页面设计说明

## 1. 页面名称

```text
场景约束
```

## 2. 所属模块

```text
模型配置 / Step 4：场景约束
```

## 3. 页面定位

场景约束页面是模型配置流程的第四步，用于配置本次调度计算所采用的业务场景、调水条件、冲沙流量、工程运行状态、生态流量要求以及相关约束条件。

本页面应延续首页、模型数据、基础配置、模型算法页面的深色智慧水利科研平台风格，保持深色写实科技风、蓝青色高亮、半透明面板、专业后台系统视觉。

------

## 4. 页面开发目标

本页面当前阶段需要实现：

```text
1. 展示模型配置顶部五步流程。
2. 高亮当前步骤“场景约束”。
3. 展示场景配置区域。
4. 支持“典型场景 / 自定义场景”切换。
5. 展示场景描述输入区。
6. 展示场景参数配置区。
7. 展示约束条件展示区。
8. 支持取消、保存、下一步操作。
9. 点击“下一步”进入 Step 5：配置汇总页面。
```

当前阶段不实现：

```text
1. 不调用后端接口。
2. 不连接数据库。
3. 不调用 MATLAB。
4. 不做真实约束冲突校验。
5. 不做真实场景计算。
6. 不做真实参数入库。
7. 不生成真实计算任务。
```

## 5. 页面整体布局

场景约束页面采用：

```text
顶部系统栏 + 模型配置五步流程条 + 场景配置内容区 + 底部操作栏
```

页面结构如下：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部系统栏：系统名称 / 导航菜单 / 当前时间  / 状态 │
├──────────────────────────────────────────────────────────────┤
│ 模型配置五步流程：模型数据 → 基础配置 → 模型算法 → 场景约束 → 配置汇总 │
├──────────────────────────────────────────────────────────────┤
│ 场景配置标题区                                                 │
│ 典型场景 / 自定义场景 切换                                     │
├──────────────────────────────────────────────────────────────┤
│ 场景描述                                                       │
├──────────────────────────────┬───────────────────────────────┤
│ 场景参数配置                   │ 约束条件展示                  │
├──────────────────────────────┴───────────────────────────────┤
│ 底部操作栏：取消 / 保存 / 下一步                              │
└──────────────────────────────────────────────────────────────┘
```

布局要求：

```text
1. 页面主体保持一屏展示。
2. 上方为场景模式选择和场景描述。
3. 下方左侧为场景参数配置。
4. 下方右侧为约束条件展示。
5. 页面整体不做密集数据大屏。
6. 卡片之间留出清晰间距。
7. 底部操作栏与前面步骤保持一致。
```

## 7. 模型配置五步流程条

## 7.1 正确步骤内容

注意：上传原型图中展示为 4 个步骤，这是旧版本，不采用。

本项目统一使用 5 个步骤：

```text
1 模型数据
2 基础配置
3 模型算法
4 场景约束
5 配置汇总
```

每个步骤说明为：

```text
模型数据：选择与管理模型输入数据
基础配置：设置调度规则与工程目标
模型算法：选择模型与优化算法
场景约束：布置调度场景与约束条件
配置汇总：确认配置并开始计算
```

## 7.2 当前步骤状态

当前页面为第四步：

```text
场景约束
```

展示要求：

```text
1. “4 场景约束”高亮显示。
2. “1 模型数据”“2 基础配置”“3 模型算法”显示为已完成状态。
3. “5 配置汇总”为未激活状态。
4. 步骤编号使用圆形数字。
5. 步骤之间使用箭头或连接线表达流程关系。
6. 样式与模型配置前面三个步骤保持一致。
```

## 7.3 交互规则

```text
1. 点击 Step 1 可返回模型数据页面。
2. 点击 Step 2 可返回基础配置页面。
3. 点击 Step 3 可返回模型算法页面。
4. 当前 Step 4 保持高亮。
5. 未完成 Step 5 当前阶段可不允许直接跳转。
6. 点击底部“下一步”进入 Step 5：配置汇总。
7. 步骤切换只做前端路由跳转或前端状态切换。
```

推荐路由：

```text
/model-config/model-data
/model-config/basic-config
/model-config/model-algorithm
/model-config/scenario-constraint
/model-config/config-summary
```

## 14. 页面交互规则

### 14.1 场景类型切换

```text
1. 默认选中“典型场景”。
2. 点击“自定义场景”后切换为自定义场景状态。
3. 自定义场景允许用户编辑场景描述和参数。
4. 当前阶段只保存前端状态。
```

### 14.2 场景描述

```text
1. 场景描述最多 300 字。
2. 输入时实时更新字数统计。
3. 为空时点击下一步可提示“请填写场景描述”。
4. 当前阶段不调用接口。
```

### 14.3 场景参数

```text
1. 每个参数通过下拉选择框配置。
2. 参数修改后保存到页面状态或 Pinia。
3. 不做真实约束推导。
4. 不做真实数据校验。
```

### 14.4 约束条件展示

```text
1. 约束列表只读展示。
2. 所有约束默认显示“已配置”。
3. 约束数量根据 mock 列表自动统计。
4. 当前阶段不支持编辑约束。
```

### 14.5 保存

```text
1. 点击保存后保存当前场景约束配置。
2. 可使用 Element Plus Message 提示“场景约束配置已保存”。
3. 不调用后端接口。
```

### 14.6 下一步

```text
1. 点击下一步进入配置汇总页面。
2. 推荐路由为 /model-config/config-summary。
```
