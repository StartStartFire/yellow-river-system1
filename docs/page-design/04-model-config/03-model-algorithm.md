# 模型配置 Step 3：模型算法页面设计说明

## 1. 页面名称

```text
模型算法
```

## 2. 所属模块

```text
模型配置 / Step 3：模型算法
```

## 3. 页面定位

模型算法页面是模型配置流程的第三步，用于选择本次调度计算所使用的调度模型、优化算法，并配置对应算法参数。

本页面应延续首页和模型配置前两个步骤的深色科技风、蓝青色高亮、半透明面板、专业水利科研平台风格。

------

## 4. 页面开发目标

本页面当前阶段需要实现：

```text
1. 展示模型配置顶部五步流程。
2. 高亮当前步骤“模型算法”。
3. 展示调度模型选择区域。
4. 展示优化算法选择区域。
5. 展示算法参数设置区域。
6. 支持参数滑块调整。
7. 支持参数数值输入或展示。
8. 支持参数说明提示。
9. 支持取消、保存、下一步操作。
10. 点击“下一步”进入 Step 4：场景约束页面。
```

当前阶段不实现：

```text
1. 不调用真实模型。
2. 不执行真实优化算法。
3. 不调用 MATLAB。
4. 不调用后端接口。
5. 不连接数据库。
6. 不做真实参数有效性校验。
7. 不做真实模型运行。
```

------

## 5. 页面整体布局

模型算法页面采用：

```text
顶部系统栏 + 模型配置五步流程条 + 模型与算法选择区 + 算法参数设置区 + 底部操作栏
```

页面结构如下：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部系统栏：系统名称 / 导航菜单 / 当前时间 /  状态 │
├──────────────────────────────────────────────────────────────┤
│ 模型配置五步流程：模型数据 → 基础配置 → 模型算法 → 场景约束 → 配置汇总 │
├──────────────────────────────────────────────────────────────┤
│ 模型与算法选择区：调度模型选择        | 优化算法选择          │
├──────────────────────────────────────────────────────────────┤
│ 算法参数设置区：种群规模 / 迭代次数 / 交叉概率 / 变异概率 / 精英保留比例 / 拥挤度因子 │
├──────────────────────────────────────────────────────────────┤
│ 底部操作栏：取消 / 保存 / 下一步                              │
└──────────────────────────────────────────────────────────────┘
```

布局要求：

```text
1. 页面主体保持一屏展示。
2. 上半部分为模型与算法选择。
3. 下半部分为算法参数设置。
4. 参数卡片横向排列。
5. 底部操作栏与前两个步骤保持一致。
```

## 7. 模型配置五步流程条

## 7.1 正确步骤内容

本项目统一使用 5 个步骤：

```text
1 模型数据
2 基础配置
3 模型算法
4 场景约束
5 配置汇总
```

每个步骤说明为：

```text
模型数据：选择与管理模型输入数据
基础配置：设置调度规则与工程目标
模型算法：选择模型与优化算法
场景约束：布置调度场景与约束条件
配置汇总：确认配置并开始计算
```

## 7.2 当前步骤状态

当前页面为第三步：

```text
模型算法
```

展示要求：

```text
1. “3 模型算法”高亮显示。
2. 步骤编号使用圆形数字。
3. 步骤之间使用箭头或连接线表达流程关系。
4. 样式与 Step 1、Step 2 保持一致。
```

## 7.3 交互规则

```text
1. 点击 Step 1 可返回模型数据页面。
2. 点击 Step 2 可返回基础配置页面。
3. 当前 Step 3 保持高亮。
4. 未完成步骤当前阶段可不允许直接跳转。
5. 点击底部“下一步”进入 Step 4：场景约束。
6. 步骤切换只做前端路由跳转或前端状态切换。
```

推荐路由：

```text
/model-config/model-data
/model-config/basic-config

```

## 9. 内容区二：算法参数设置

## 9.1 区域标题

标题显示：

```text
算法参数设置
```

标题左侧可使用参数、设置或滑块类图标。

## 9.2 区域位置

位于页面主体下半部分，横向占满内容区宽度。

## 9.3 参数卡片

参数以卡片形式横向排列。

默认展示 6 个参数：

```text
种群规模
迭代次数
交叉概率 Pc
变异概率 Pm
精英保留比例
拥挤度因子
```

每个参数卡片包含：

```text
1. 参数名称
2. 参数说明图标
3. 参数滑块
4. 最小值
5. 最大值
6. 当前值输入框或数值框
```

------

## 9.4 参数一：种群规模

显示名称：

```text
种群规模
```

默认值：

```text
200
```

范围：

```text
50 - 1000
```

说明：

```text
种群规模越大，搜索更充分，结果更稳定，但计算耗时增加；种群规模越小，计算更快，但容易遗漏优良解。
```

------

## 9.5 参数二：迭代次数

显示名称：

```text
迭代次数
```

默认值：

```text
500
```

范围：

```text
100 - 2000
```

说明：

```text
迭代次数越大，收敛更充分，但运行时间更长；迭代次数越小，运行更快，但可能未充分收敛。
```

------

## 9.6 参数三：交叉概率 Pc

显示名称：

```text
交叉概率 Pc
```

默认值：

```text
0.90
```

范围：

```text
0.50 - 1.00
```

说明：

```text
交叉概率越高，种群探索能力更强；交叉概率越低，解集变化较慢，可能影响搜索效率。
```

------

## 9.7 参数四：变异概率 Pm

显示名称：

```text
变异概率 Pm
```

默认值：

```text
0.10
```

范围：

```text
0.01 - 0.30
```

说明：

```text
变异概率越高，跳出局部最优能力更强，但过高会导致结果波动；变异概率越低，结果更稳定，但探索不足。
```

------

## 9.8 参数五：精英保留比例

显示名称：

```text
精英保留比例
```

默认值：

```text
0.05
```

范围：

```text
0.01 - 0.20
```

说明：

```text
精英保留比例越高，保留优良解更多，但可能降低种群多样性；精英保留比例越低，多样性更高，但优良解可能丢失。
```

------

## 9.9 参数六：拥挤度因子

显示名称：

```text
拥挤度因子
```

默认值：

```text
2.00
```

范围：

```text
1.00 - 3.00
```

说明：

```text
拥挤度因子用于控制解集分布的均匀性，数值越大越强调解集分散性，数值越小越强调局部收敛效果。
```

------

## 9.10 参数卡片样式

```text
1. 参数卡片横向排列。
2. 每个参数卡片宽度一致。
3. 卡片背景使用深色半透明。
4. 卡片边框使用蓝青色细线。
5. 参数名称位于左上角。
6. 说明图标位于右上角。
7. 滑块位于中部。
8. 最小值和最大值位于滑块两端下方。
9. 当前值位于底部输入框中。
10. 当前值字体较大，居中显示。
```

Element Plus 组件需要适配深色主题，按钮、表单、弹窗等应与系统深色风格统一。

## 14. 页面交互规则

### 14.1 模型选择

```text
1. 默认选择“水库群优化调度模型”。
2. 用户切换模型后，算法下拉框同步刷新。
3. 若当前算法不属于新模型支持范围，则自动清空或切换为第一个可用算法。
4. 当前阶段只使用 mock 数据。
```

### 14.2 算法选择

```text
1. 默认选择“NSGA-II 多目标遗传算法”。
2. 用户切换算法后，下方参数可以更新为对应算法参数。
3. 当前阶段可先统一展示 NSGA-II 参数。
4. 不执行真实算法。
```

### 14.3 参数调整

```text
1. 参数通过滑块调整。
2. 参数值同步显示在底部数值框。
3. 数值框可支持手动输入。
4. 输入超出范围时前端提示。
5. 参数变化保存到 Pinia 或页面状态。
```

### 14.4 参数说明

```text
1. 鼠标悬浮问号图标显示参数说明。
2. 参数说明应解释参数高低变化影响。
3. 不需要跳转到帮助文档。
```

### 14.5 保存

```text
1. 点击保存后弹出确认弹窗。
2. 确认后保存当前模型算法配置。
3. 可使用 Element Plus Message 提示“模型算法配置已保存”。
4. 不调用接口。
```
