# 模型配置 Step 3：模型算法页面设计说明

## 1. 页面名称

```text
模型算法
```

## 2. 所属模块

```text
模型配置 / Step 3：模型算法
```

## 3. 页面定位

模型算法页面是模型配置流程的第三步，用于选择本次调度计算所使用的调度模型、优化算法，并配置对应算法参数。

本页面应延续首页和模型配置前两个步骤的深色科技风、蓝青色高亮、半透明面板、专业水利科研平台风格。

------

## 4. 页面开发目标

本页面当前阶段需要实现：

```text
1. 展示模型配置顶部五步流程。
2. 高亮当前步骤"模型算法"。
3. 展示调度模型选择区域。
4. 展示优化算法选择区域。
5. 展示算法参数设置区域。
6. 支持参数滑块调整。
7. 支持参数数值输入或展示。
8. 支持参数说明提示。
9. 支持取消、保存、下一步操作（使用 ModelConfigFooter 公用组件）。
10. 点击"下一步"进入 Step 4：场景约束页面。
```

当前阶段不实现：

```text
1. 不调用真实模型。
2. 不执行真实优化算法。
3. 不调用 MATLAB。
4. 不调用后端接口。
5. 不连接数据库。
6. 不做真实参数有效性校验。
7. 不做真实模型运行。
```

------

## 5. 页面整体布局

模型算法页面采用：

```text
顶部系统栏 + 模型配置五步流程条 + 模型与算法选择区 + 算法参数设置区 + 底部操作栏（公用组件）
```

页面结构如下：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部系统栏：系统名称 / 导航菜单 / 当前时间 /  状态 │
├──────────────────────────────────────────────────────────────┤
│ 模型配置五步流程：模型数据 → 基础配置 → 模型算法 → 场景约束 → 配置汇总 │
├──────────────────────────────────────────────────────────────┤
│ 模型与算法选择区：调度模型选择        | 优化算法选择          │
├──────────────────────────────────────────────────────────────┤
│ 算法参数设置区：种群规模 / 迭代次数 / 交叉概率 / 变异概率 / 精英保留比例 / 拥挤度因子 │
├──────────────────────────────────────────────────────────────┤
│ 底部操作栏（ModelConfigFooter）：取消 / 上一步 / 保存 / 下一步 │
└──────────────────────────────────────────────────────────────┘
```

（其余内容与原有设计一致，包括调度模型选择、优化算法选择、算法参数设置等，保持不变）

## 6. 步骤间联动说明

本页面与 Step 2（基础配置）存在联动关系：

### 6.1 水库组合 → 模型筛选

```text
Step 2 选择的水库组合决定了 Step 3 可选的调度模型范围：
  · 龙刘组合 → LRO、多目标协同胁迫模型
  · 龙刘黑组合 → LRO、多目标优化调度、水沙实时调度
  · 龙刘青组合 → LRO、多目标优化调度
  · 全部水库组合 → 多目标优化调度、水沙实时调度、LRO
```

当用户在 Step 2 切换水库组合时，若当前模型不被新组合支持，会自动切换到第一个兼容模型。

### 6.2 时间步长 → 算法参数建议

```text
Step 2 选择的时间步长会建议 Step 3 的算法参数：
  · 每日 → 种群规模 200、迭代次数 500
  · 每旬 → 种群规模 150、迭代次数 300
  · 每月 → 种群规模 100、迭代次数 200
```

参数建议在用户点击 Step 2 的"下一步"或"保存"时自动应用。

### 6.3 联动视觉反馈

模型选择下拉框下方显示提示文字，标明当前模型列表是由哪个水库组合筛选的。
