# 模型配置 Step 1：模型数据页面设计说明

## 1. 页面名称

```text
模型数据
```

## 2. 所属模块

```text
模型配置 / Step 1：模型数据
```

## 3. 页面定位

模型数据页面是模型配置流程的第一步，用于选择、上传、查看和管理本次模型计算所需的输入数据。

页面数据全部来自：

```text
src/mock/modelConfig.ts
```

本页面应延续首页和全局页面规范中的深色写实科技风、蓝青色高亮、半透明面板、专业水利科研平台风格。全局规范要求页面采用深色科技风、中国水利调度主题、16:9 宽屏布局，并保持专业、严谨、清晰的视觉特征。

------

## 4. 页面开发目标

本页面当前阶段需要实现：

```text
1. 展示模型配置顶部五步流程。
2. 高亮当前步骤“模型数据”。
3. 展示左侧数据目录。
4. 默认选中“入库与水位”。
5. 展示右侧操作区：上传数据、下载模板、时间范围。
6. 展示输入数据概览图表。
7. 支持左侧目录切换。
8. 支持底部取消、保存、下一步按钮。
9. 点击“下一步”进入 Step 2：基础配置。
```

当前阶段不实现：

```text
1. 不做真实 Excel 上传。
2. 不做真实模板下载。
3. 不做真实字段校验。
4. 不做真实数据解析。
5. 不调用后端接口。
6. 不连接数据库。
7. 不调用 MATLAB。
```

------

## 5. 页面整体布局

页面采用：

```text
顶部系统栏 + 模型配置流程步骤条 + 左侧数据目录 + 右侧数据展示区 + 底部操作栏
```

结构如下：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部系统栏：系统名称 / 导航菜单 / 当前时间/ 状态 │
├──────────────────────────────────────────────────────────────┤
│ 模型配置流程步骤条：模型数据 → 基础配置 → 模型算法 → 场景约束 → 配置汇总 │
├───────────────┬──────────────────────────────────────────────┤
│ 左侧数据目录   │ 右侧内容区                                   │
│               │ 顶部操作区：上传数据 / 下载模板 / 时间范围    │
│ 调度输入       │                                              │
│ 原始表格       │ 输入数据概览图表                             │
│               │                                              │
├───────────────┴──────────────────────────────────────────────┤
│ 底部操作栏：取消 / 保存 / 下一步                              │
└──────────────────────────────────────────────────────────────┘
```

布局比例建议：

```text
左侧数据目录：20%
右侧内容区：80%
```

页面应尽量适配 1920×1080 一屏展示，避免出现大量纵向滚动。

## 7. 模型配置流程步骤条

### 7.1 步骤内容

页面顶部展示五步流程：

```text
1 模型数据
2 基础配置
3 模型算法
4 场景约束
5 配置汇总
```

每个步骤包含主标题和简短说明：

```text
模型数据：选择与管理模型输入数据
基础配置：设置调度规则与工程目标
模型算法：选择模型与优化算法
场景约束：布置调度场景与约束条件
配置汇总：确认配置并开始计算
```

### 7.2 当前步骤状态

当前页面为第一步：

```text
模型数据
```

展示要求：

```text
1. “1 模型数据”高亮显示。
2. 其他步骤为未激活状态。
3. 步骤之间使用箭头或连接线表示流程关系。
4. 步骤编号使用圆形数字。
5. 当前步骤背景可使用蓝色渐变或高亮边框。
```

### 7.3 交互要求

```text
1. 当前阶段允许点击已完成步骤或当前步骤。
2. 未完成步骤可暂不允许直接跳转。
3. 点击“下一步”后进入 Step 2：基础配置。
4. 步骤切换只在前端完成，不调用接口。
```
