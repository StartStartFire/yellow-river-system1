# 模型配置 Step 2：调度主体页面设计说明

## 1. 页面名称

```text
调度主体
```

## 2. 所属模块

```text
模型配置 / Step 2：调度主体
```

## 3. 页面定位

调度主体页面是模型配置六步流程的**第二步**，用于确定本次调度计算的**时间范围、计算步长、调度频率**以及**参与调度的水库**。

本页面承接 Step 1 的场景选择（自动预填默认值），向下传递到 Step 3 模型数据的时间范围筛选和 Step 4 模型算法的水库兼容性判断。

---

## 4. 页面开发目标

当前阶段需要实现：

```text
1. 显示顶部模型配置 6 步流程步骤条（当前高亮 Step 2，Step 1 已完成）
2. 上半部分：调度时段与周期设置区
   - 起止时间（日期选择器）
   - 时间步长（下拉选择）
   - 调度频率（下拉选择）
   - 总时段数（自动计算，只读展示）
3. 下半部分：水库选择区
   - 预设水库组合（快捷卡片）
   - 自定义水库多选（自由勾选）
   - 两种模式联动：选预设时自动勾选对应水库，手动勾选时取消预设选中
4. 底部操作栏：取消 / 上一步 / 保存 / 下一步
5. 联动 Step 1：根据场景自动预填时间范围和步长
```

## 6. 上半区：调度时段与周期

### 6.1 区域定位

位于页面上半部分，包含 4 个参数设置项，采用 2×2 网格排列。

### 6.2 调度起止时间

| 属性 | 说明 |
|------|------|
| 字段名称 | 调度起止时间 |
| 控件类型 | Element Plus 日期范围选择器（el-date-picker type="daterange"） |
| 格式 | YYYY-MM-DD |
| 默认值 | 联动 Step 1 场景自动预填（见 §9 联动规则） |

要求：

```text
1. 控件适配深色主题
2. 选择时间范围后自动计算总时段数
3. 日期范围选择器宽度撑满卡片
```

### 6.3 时间步长

| 属性 | 说明 |
|------|------|
| 字段名称 | 时间步长 |
| 控件类型 | Element Plus Select 下拉框 |
| 选项 | 每日 / 每旬 / 每月 |

要求：

```text
1. 切换步长后自动重新计算总时段数
2. 联动 Step 1 场景自动预填建议步长
```

### 6.4 调度频率

| 属性 | 说明 |
|------|------|
| 字段名称 | 调度频率 |
| 控件类型 | Element Plus Select 下拉框 |
| 选项 | 每月一次 / 每旬一次 / 每周一次 / 不限制 |

要求：

```text
1. 当前阶段不做实际校验
2. 默认值可联动预填
```

### 6.5 总时段数

| 属性 | 说明 |
|------|------|
| 字段名称 | 总时段数 |
| 控件类型 | 只读展示（非输入框） |
| 计算方式 | 根据起止时间和步长自动计算 |

计算公式：

```text
每日：起止日期之差（天）+ 1
每旬：ceil(天数差 / 10)
每月：ceil(天数差 / 30)
```

要求：

```text
1. 使用大号数字 + "时段"单位展示
2. 随起止时间或步长变化即时更新
3. 放置在调度周期卡片标题栏右侧或独立展示
```

### 7.3 预设组合

| 组合ID | 名称 | 包含水库 | 说明 |
|--------|------|---------|------|
| long-liu | 龙刘组合 | 龙羊峡水库、刘家峡水库 | 上游两大控制性水库 |
| long-liu-hei | 龙刘黑组合 | 龙羊峡水库、刘家峡水库、黑山峡水库 | 上游+黑山峡 |
| all | 全部水库 | 全部 5 座水库 | 系统所有水库 |

### 7.4 预设组合交互规则

```text
1. 预设组合以卡片按钮形式展示，横向排列
2. 点击某个预设组合卡片 → 自动选中该卡片（高亮）→ 下方水库列表自动勾选对应水库
3. 再次点击已选中的预设组合 → 取消选中 → 不清空水库勾选
4. 预设卡片之间互斥（只能选中一个预设组合）
5. 选中预设后，如果用户在下方列表中手动勾选/取消某个水库，预设卡片的选中态自动取消
6. 预设卡片选中态：蓝色边框高亮 + 勾选标记
```

### 7.5 自定义多选交互规则

```text
1. 显示系统所有水库列表，每行一个水库
2. 每行左侧为 checkbox 勾选框
3. 每行显示水库名称 + 辅助信息（当前水位、入库流量、运行状态）
4. 辅助信息帮助用户判断该水库是否需要参与调度
5. 全部未勾选时，不可进入下一步
6. 勾选数量无上限
7. 勾选变化自动取消预设组合选中态
```

## 9. Step 1 → Step 2 联动规则

### 9.1 联动映射表

| Step 1 子选项 | 预填起止时间 | 预填步长 | 预填频率 | 预填水库 |
|--------------|------------|---------|---------|---------|
| 多目标优化调度 | 全年（2025-01-01 ~ 2025-12-31） | 每月 | 每月一次 | 全部水库 |
| 防洪期 | 汛期（2025-06-01 ~ 2025-09-30） | 每日 | 不限制 | 龙刘组合 |
| 防凌期 | 凌汛期（2025-11-01 ~ 2026-03-31） | 每日 | 不限制 | 龙刘组合 |
| 供水期 | 供水期（2025-03-01 ~ 2025-06-30） | 每旬 | 每旬一次 | 龙刘组合 |
| 调水调沙 | 汛期（2025-07-01 ~ 2025-08-31） | 每日 | 不限制 | 龙刘组合 |
| 凌峰水沙调度 | 凌汛期（2025-11-01 ~ 2026-03-31） | 每日 | 不限制 | 龙刘组合 |
| 断面输沙调度 | 全年（2025-01-01 ~ 2025-12-31） | 每日 | 每月一次 | 龙刘黑组合 |
| 区间冲淤调度 | 全年（2025-01-01 ~ 2025-12-31） | 每日 | 每月一次 | 全部水库 |
| 多能互补 | 全年（2025-01-01 ~ 2025-12-31） | 每日 | 不限制 | 全部水库 |

### 9.2 联动交互说明

```text
1. 进入 Step 2 时，从 Store 读取 Step 1 的 dispatchScenario.subOptionId
2. 根据上述映射表自动预填所有字段
3. 所有预填值用户均可手动修改
4. 用户修改后以手动输入为准（不覆盖用户修改）
5. 用户点击"上一步"返回 Step 1 再回来时，重置为最新预填值
```
