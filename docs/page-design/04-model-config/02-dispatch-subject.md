# 模型配置 Step 2：调度主体页面设计说明

## 1. 页面名称

```text
调度主体
```

## 2. 所属模块

```text
模型配置 / Step 2：调度主体
```

## 3. 页面定位

调度主体页面是模型配置六步流程的**第二步**，用于确定本次调度计算的**时间范围、计算步长、调度频率**以及**参与调度的水库**。

本页面承接 Step 1 的场景选择（自动预填默认值），向下传递到 Step 3 模型数据的时间范围筛选和 Step 4 模型算法的水库兼容性判断。

---

## 4. 页面开发目标

当前阶段需要实现：

```text
1. 显示顶部模型配置 6 步流程步骤条（当前高亮 Step 2，Step 1 已完成）
2. 上半部分：调度时段与周期设置区
   - 起止时间（日期选择器）
   - 时间步长（下拉选择）
   - 调度频率（下拉选择）
   - 总时段数（自动计算，只读展示）
3. 下半部分：水库选择区
   - 预设水库组合（快捷分区）
   - 自定义水库多选（自由勾选）
   - 两种模式联动：选预设时自动勾选对应水库，手动勾选时取消预设选中
4. 底部操作栏：取消 / 上一步 / 保存 / 下一步
5. 联动 Step 1：根据场景自动预填时间范围和步长
```

## 6. 上半区：调度时段与周期

### 6.1 区域定位

位于页面上半部分，包含 4 个参数设置项，采用 2×2 网格排列。

### 6.2 调度起止时间

| 属性 | 说明 |
|------|------|
| 字段名称 | 调度起止时间 |
| 控件类型 | Element Plus 日期范围选择器（el-date-picker type="daterange"） |
| 格式 | YYYY-MM-DD |
| 默认值 | 联动 Step 1 场景自动预填（见 §9 联动规则） |

要求：

```text
1. 控件适配深色主题
2. 选择时间范围后自动计算总时段数
3. 日期范围选择器宽度撑满卡片
```

**场景时长约束（重要）：**

| Step 1 场景大类 | 时间范围约束 | 说明 |
|----------------|------------|------|
| 多年的中长期调度 | 1 年 ~ 5 年 | 跨年度长期规划 |
| 年内关键期调度 | ≤ 1 年（年内） | 起止日期必须在同一年内，最多 365 天 |
| 实时调度 | ≤ 1 个月（月内） | 起止日期跨度不超过 31 天 |

```text
1. 选择起止时间后自动校验是否超出场景允许范围
2. 超出范围时在控件下方显示红色提示文字
3. 用户仍可修改，但"下一步"时会校验拦截
```

### 6.3 时间步长

| 属性 | 说明 |
|------|------|
| 字段名称 | 时间步长 |
| 控件类型 | Element Plus Select 下拉框 |
| 选项 | 每日 / 每旬 / 每月 |

要求：

```text
1. 切换步长后自动重新计算总时段数
2. 联动 Step 1 场景自动预填建议步长
```

**场景约束（重要）：**

| Step 1 场景大类 | 允许的步长 | 说明 |
|----------------|-----------|------|
| 多年的中长期调度 | 每旬、每月 | 长期规划，不按日计算 |
| 年内关键期调度 | 每旬、每月 | 精细到旬/月即可 |
| 实时调度 | 仅每日（锁定） | 以日为单位，不可切换 |

```text
1. Step 1 选择后，步长下拉框根据场景类型自动过滤选项
2. 实时调度场景下步长固定为"每日"，下拉框置灰不可改
3. 切换步长时如果当前时段数因步长变化超出范围，自动提示
```

### 6.4 调度频率

| 属性 | 说明 |
|------|------|
| 字段名称 | 调度频率 |
| 控件类型 | Element Plus Select 下拉框 |
| 选项 | 每月一次 / 每旬一次 / 每周一次 / 不限制 |

要求：

```text
1. 当前阶段不做实际校验
2. 默认值可联动预填
```

### 6.5 总时段数

| 属性 | 说明 |
|------|------|
| 字段名称 | 总时段数 |
| 控件类型 | 只读展示（非输入框） |
| 计算方式 | 根据起止时间和步长自动计算 |

计算公式：

```text
每日：起止日期之差（天）+ 1
每旬：ceil(天数差 / 10)
每月：ceil(天数差 / 30)
```

要求：

```text
1. 使用大号数字 + "时段"单位展示
2. 随起止时间或步长变化即时更新
3. 放置在调度周期卡片标题栏右侧或独立展示
```

### 7.4 预设组合交互规则

```text
1. 预设组合以分区按钮形式展示，横向排列（含"更多组合"共 4 个分区）
2. 点击某个预设组合卡片 → 自动选中该卡片（蓝色高亮）→ 自动勾选对应水库
3. 再次点击已选中的预设组合 → 取消选中 → 不清空已选水库
4. 预设分区之间互斥（一次只能选中一个预设）
5. 点击另一个预设组合 → 切换到新组合（替换水库勾选）
```

### 9.2 联动交互说明

```text
1. 进入 Step 2 时，从 Store 读取 Step 1 的 dispatchScenario.subOptionId

3. 所有预填值用户均可手动修改
4. 用户修改后以手动输入为准（不覆盖用户修改）
5. 用户点击"上一步"返回 Step 1 再回来时，重置为最新预填值
```

```text

```

### 12.2 场景时长约束校验（重要）

| 场景大类 | 校验规则 | 错误提示 |

| 多年的中长期调度 | 跨度 ≥ 1 年 且 ≤ 5 年 | "中长期调度时间跨度应不少于 1 年且不超过 5 年" |

| 实时调度 | 跨度 ≤ 31 天 | "实时调度时间范围不能超过 31 天" |

### 12.3 步长合法性校验
