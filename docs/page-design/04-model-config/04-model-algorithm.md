# 模型配置 Step 4：模型算法页面设计说明

## 1. 页面名称

```text
模型算法
```

## 2. 所属模块

```text
模型配置 / Step 4：模型算法
```

## 3. 页面定位

模型算法页面是模型配置六步流程的**第四步**，在本页面中完成三项核心配置：

1. **选择调度模型与优化算法** — 选择计算使用的模型和算法，配置算法参数
2. **选择调度目标** — 根据 Step 1 场景联动默认填充，用户可在此微调
3. **设置约束条件** — 控制调度计算的边界条件，弹窗中精细编辑

本页面合并了旧流程 Step 3（模型算法）的全部内容 + 旧流程 Step 2 中的调度目标与约束条件。

---

## 4. 页面开发目标

```text
1. 显示顶部模型配置 6 步步骤条（Step 4 高亮，Step 1~3 已完成）
2. 左右分区布局：
   - 左侧：模型选择 + 算法选择 + 参数设置
   - 右侧：调度目标选择 + 约束条件设置
3. 调度目标从 Step 1 联动预填，用户可增删改
4. 约束条件弹窗编辑（延续弹窗+开关+数值编辑设计）
5. 底部操作栏：取消 / 上一步 / 保存 / 下一步
```

## 6. 左侧：模型与算法

左侧区域保留原 ModelAlgorithmView.vue 的完整内容，包含：

### 6.1 调度模型选择

| 属性 | 说明 |
|------|------|
| 控件 | Element Plus Select 下拉框 |
| 选项来源 | 根据 Step 2 水库组合过滤（当前仅支持龙刘组合/龙刘黑组合） |
| 联动 | 切换模型自动检查算法兼容性，不兼容则自动切换 |

```text
当前支模型列表：
  lro                          — 水库群优化调度模型（LRO）
  multi_objective_stress       — 多目标协同胁迫模型
  multi_objective_dispatch     — 多目标优化调度模型
  water_sediment_realtime      — 水沙实时调度模型（WSS）
```

### 6.2 优化算法选择

| 属性 | 说明 |
|------|------|
| 控件 | Element Plus Select 下拉框 |
| 选项来源 | 根据所选模型支持的算法过滤 |
| 联动 | 切换算法自动更新参数列表和默认值 |

```text
当前支持的算法：
  NSGA-II    — 多目标遗传算法
  PSO        — 粒子群优化算法
  PAEM       — 逐步逼近评价方法
  NSGA-III   — 多目标遗传算法
```

### 6.3 算法参数设置

保留原左列表（参数名+当前值）+ 右详情（数值输入+滑块+范围提示+说明）的布局。

## 7. 右侧：调度目标 + 约束条件

### 7.1 调度目标选择

| 属性 | 说明 |
|------|------|
| 控件 | 分区列表多选（点击选中/取消） |
| 默认值 | 从 Step 1 联动预填（可修改） |
| 最小选择 | 至少选择 1 个目标 |

```text
可选项（5 项目标）：
  ┌─────────────────────────────────────────┐
  │  ✅ 防洪安全   保障水库防洪安全          │
  │  ☐ 兴利发电   优化发电出力              │
  │  ✅ 生态保护   保障生态流量              │
  │  ☐ 输沙调度   优化水沙过程              │
  │  ☐ 多能互补   协调水电与新能源          │
  └─────────────────────────────────────────┘
```

交互规则：

```text
1. 每个目标为一个可点击分区项，点击切换选中态
2. 选中态显示蓝色边框+勾选标记
3. 至少保留一项选中（取消最后一个时会自动阻止）
4. 修改后实时更新到本地状态
```

### 7.2 约束条件

| 属性 | 说明 |
|------|------|
| 控件 | 摘要分区 + 弹窗编辑 |

| 编辑方式 | 弹窗内 el-switch 开关 + el-input-number 数值编辑 |

## 8. 布局与样式规范

### 8.1 左右分区比例

```text
左侧（模型+算法）：右侧（目标+约束）= 3 : 2
或 左侧 65% : 右侧 35%
```

### 8.2 右侧内部比例

```text
调度目标 ：约束条件 = 1 : 1（上下各占一半）
```

### 8.3 右侧区域风格

```css
/* 右侧通用分区 — 无独立卡片，使用统一面板背景 + 分割线 */

border-bottom: 1px solid rgba(0, 175, 255, 0.08);

/* 调度目标分区项 - 选中态（下划线高亮） */
border-bottom-color: rgba(0, 212, 255, 0.6);
background: rgba(0, 175, 255, 0.06);

/* 约束摘要分区 */
/* 保持与 BasicConfigView 现有风格一致 */
```

## 9. 数据流转

### 9.1 输入：Step 1 → Step 2 联动

```text
Step 1 子选项 → selectedObjectives（调度目标）
```

示例：
- 防洪期 → ['flood-control']
- 多目标优化调度 → ['flood-control', 'power-generation', 'ecology']

### 9.2 写入 Store

```text
modelAlgorithm（模型/算法/参数）← 左侧内容
basicConfig.selectedObjectives（调度目标）← 右侧选择
basicConfig.constraintEnabled（约束开关）← 弹窗编辑
```

### 9.3 输出到后续步骤

```text
Step 5 场景配置：读取 modelAlgorithm + selectedObjectives
Step 6 配置汇总：读取全部配置展示摘要
```

