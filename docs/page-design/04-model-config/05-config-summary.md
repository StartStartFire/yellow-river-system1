# 模型配置 Step 5：配置汇总页面设计说明

## 1. 页面名称

```text
配置汇总
```

## 2. 所属模块

```text
模型配置 / Step 5：配置汇总
```

## 3. 页面定位

配置汇总页面是模型配置流程的最后一步，用于集中展示已配置的调度方案，提供方案管理和一键运行入口。

本页面应延续首页和模型配置前四步页面的深色智慧水利科研平台风格，保持深色写实科技风、蓝青色高亮、半透明面板、专业后台系统视觉。

------

## 4. 页面开发目标

本页面当前阶段需要实现：

```text
1. 展示模型配置顶部五步流程。
2. 高亮当前步骤"配置汇总"。
3. 展示配置方案列表（搜索、筛选、分页）。
4. 支持方案勾选。
5. 支持详情、编辑、复制、删除、运行等操作按钮。
6. 详情弹窗展示 Store 中前四步的实时配置摘要。
7. 展示右侧预计计算信息（时间预估、方案数量、模型分布、算法分布）。
8. 支持一键运行按钮。
9. 支持导出配置按钮 UI。
10. 点击"一键运行"后跳转过程透明页面。
```

当前阶段不实现：

```text
1. 不调用后端接口。
2. 不连接数据库。
3. 不调用 MATLAB。
4. 不执行真实模型计算。
5. 不做真实方案新增。
6. 不做真实方案编辑。
7. 不做真实方案删除。
8. 不做真实导出配置。
9. 不做真实任务队列。
```

------

## 5. 页面整体布局

配置汇总页面采用：

```text
顶部系统栏 + 模型配置五步流程条 + 左侧配置方案表格 + 右侧预计计算信息 + 底部操作栏
```

页面结构如下：

```text
┌──────────────────────────────────────────────────────┬───────────┐
│ 顶部系统栏：系统名称 / 导航菜单 / 当前时间  / 状态 │
├──────────────────────────────────────────────────────┤
│ 模型配置五步流程：模型数据 → 基础配置 → 模型算法 → 场景约束 → 配置汇总 │
├────────────────────────────────────────┬─────────────┤
│ 配置汇总表格区                         │ 预计计算信息 │
│ 新增 / 筛选 / 搜索                     │ 时间预估     │
│ 方案列表表格                            │ 方案数量     │
│ 分页                                    │ 模型分布     │
│                                         │ 算法分布     │
├────────────────────────────────────────┴─────────────┤
│ 底部操作栏：上一步 / 一键运行 / 导出配置（居中）         │
└──────────────────────────────────────────────────────┘
```

布局要求：

```text
1. 页面主体保持一屏展示。
2. 左侧表格为主要区域。
3. 右侧预计计算信息为辅助区域。
4. 底部操作栏居中排列。
5. 页面不做密集数据大屏。
6. 信息层级清晰，表格区域和统计区域边界明确。
```

------

## 6. 底部操作栏

Step 5 使用独立底部布局，不是 ModelConfigFooter 公用组件。

按钮布局（居中）：

```text
上一步 | 一键运行 | 导出配置
```

### 6.1 上一步按钮

点击返回 Step 4 场景约束页面。

### 6.2 一键运行按钮

交互要求：

```text
1. 点击后检查是否至少选择一个方案。
2. 如果未选择方案，提示"请至少选择一个配置方案"。
3. 如果已选择方案，生成前端 mock taskId。
4. 跳转到 /process-transparent。
5. 不调用后端接口。
6. 不调用 MATLAB。
```

### 6.3 导出配置按钮

当前阶段只做 UI 或弹出提示。

## 7. 方案详情弹窗（配置摘要）

### 7.1 弹窗定位

详情弹窗从展示 mock 方案数据改为**展示 Store 中前四步的实时配置摘要**。

### 7.2 弹窗内容

弹窗按四个步骤分区块展示：

```text
┌─ 当前配置摘要 ───────────────────────────┐
│                                          │
│  ① 模型数据                              │
│     时间范围 + 数据项数                   │
│                                          │
│  ② 基础配置                              │
│     方案名称 + 水库组合 + 调度周期 + 频率  │
│                                          │
│  ③ 模型算法                              │
│     调度模型 + 优化算法 + 参数摘要         │
│                                          │
│  ④ 场景约束                              │
│     场景类型 + 西线调水 + 骨干工程 + 生态  │
│                                          │
│                         [关闭]            │
└──────────────────────────────────────────┘
```

### 7.3 数据来源

所有数据从 `useModelConfigStore()` 中读取，不使用 mock 的 `detailPlan`。

```typescript
store.modelData          // Step 1
store.basicConfig        // Step 2
store.modelAlgorithm     // Step 3
store.scenarioConstraint // Step 4
```

### 7.4 样式要求

```text
1. 弹窗宽度 640px。
2. 每个区块左上角带步骤编号徽标（①~④）。
3. 使用 el-descriptions 表格布局。
4. 深色主题适配。
5. 内容超出 480px 时滚动。
```
