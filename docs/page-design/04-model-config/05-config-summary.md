# 模型配置 Step 5：配置汇总页面设计说明

## 1. 页面名称

```text
配置汇总
```

## 2. 所属模块

```text
模型配置 / Step 5：配置汇总
```

## 3. 页面定位

配置汇总页面是模型配置流程的最后一步，用于集中展示已配置的调度方案、模型、算法、场景约束和预计计算信息，并提供一键运行入口。

本页面应延续首页和模型配置前四步页面的深色智慧水利科研平台风格，保持深色写实科技风、蓝青色高亮、半透明面板、专业后台系统视觉。

------

## 4. 页面开发目标

本页面当前阶段需要实现：

```text
1. 展示模型配置顶部五步流程。
2. 高亮当前步骤“配置汇总”。
3. 展示配置方案列表。
4. 支持方案勾选。
5. 支持方案搜索。
6. 支持新增、筛选按钮 UI。
7. 支持详情、编辑、复制、删除、运行等操作按钮 UI。
8. 展示右侧预计计算信息。
9. 展示预计运行时间、方案数量、模型分布、算法分布。
10. 支持一键运行按钮。
11. 支持导出配置按钮 UI。
12. 点击“一键运行”后跳转过程透明页面。
```

当前阶段不实现：

```text
1. 不调用后端接口。
2. 不连接数据库。
3. 不调用 MATLAB。
4. 不执行真实模型计算。
5. 不做真实方案新增。
6. 不做真实方案编辑。
7. 不做真实方案删除。
8. 不做真实导出配置。
9. 不做真实任务队列。
```

## 5. 页面整体布局

配置汇总页面采用：

```text
顶部系统栏 + 模型配置五步流程条 + 左侧配置方案表格 + 右侧预计计算信息 + 底部操作栏
```

页面结构如下：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部系统栏：系统名称 / 导航菜单 / 当前时间  / 状态 │
├──────────────────────────────────────────────────────────────┤
│ 模型配置五步流程：模型数据 → 基础配置 → 模型算法 → 场景约束 → 配置汇总 │
├──────────────────────────────────────────────┬───────────────┤
│ 配置汇总表格区                               │ 预计计算信息   │
│ 新增 / 筛选 / 搜索                            │ 时间预估       │
│ 方案列表表格                                  │ 方案数量       │
│ 分页                                          │ 模型分布       │
│                                               │ 算法分布       │
│                                               │ 说明           │
├──────────────────────────────────────────────┴───────────────┤
│ 底部操作栏：一键运行 / 导出配置 / 提示说明                    │
└──────────────────────────────────────────────────────────────┘
```

布局要求：

```text
1. 页面主体保持一屏展示。
2. 左侧表格为主要区域。
3. 右侧预计计算信息为辅助区域。
4. 底部操作栏固定在页面底部或主体下方。
5. 页面不做密集数据大屏。
6. 信息层级清晰，表格区域和统计区域边界明确。
```

## 7. 模型配置五步流程条

## 7.1 正确步骤内容

注意：上传原型图中展示为 4 个步骤，这是旧版本，不采用。

本项目统一使用 5 个步骤：

```text
1 模型数据
2 基础配置
3 模型算法
4 场景约束
5 配置汇总
```

每个步骤说明为：

```text
模型数据：选择与管理模型输入数据
基础配置：设置调度规则与工程目标
模型算法：选择模型与优化算法
场景约束：布置调度场景与约束条件
配置汇总：确认配置并开始计算
```

## 7.2 当前步骤状态

当前页面为第五步：

```text
配置汇总
```

展示要求：

```text
1. “5 配置汇总”高亮显示。
2. 步骤编号使用圆形数字。
3. 步骤之间使用箭头或连接线表达流程关系。
4. 样式与模型配置前面四个步骤保持一致。
```

## 7.3 交互规则

```text
1. 点击 Step 1 可返回模型数据页面。
2. 点击 Step 2 可返回基础配置页面。
3. 点击 Step 3 可返回模型算法页面。
4. 点击 Step 4 可返回场景约束页面。
5. 当前 Step 5 保持高亮。
6. 点击“一键运行”进入过程透明页面。
7. 步骤切换只做前端路由跳转或前端状态切换。
```

推荐路由：

```text
/model-config/model-data
/model-config/basic-config
/model-config/model-algorithm
/model-config/scenario-constraint
/model-config/config-summary
/process-transparent
```
