# 过程透明页面设计说明

## 1. 页面名称

```text
过程透明
```

## 2. 页面定位

过程透明页面用于展示模型计算任务的运行状态、方案情景、算法迭代过程、关键过程曲线、运行日志、当前最优方案、约束满足情况、预估结果摘要和操作入口。

该页面重点解决模型调度计算过程中的“黑箱问题”，通过过程曲线、迭代日志和阶段结果展示，使用户能够看到模型从开始运行到结果生成的关键过程。

页面风格必须延续首页的深色智慧水利科研平台风格，采用深蓝背景、蓝青色高亮、半透明面板、专业科研分析系统视觉。

------

## 3. 页面开发目标

本页面当前阶段需要实现：

```text
1. 展示顶部系统栏和导航栏。
2. 当前导航“过程透明”高亮。
3. 展示方案情景选择区。
4. 展示任务状态、调度周期、已运行时间、预计剩余时间、整体进度。
5. 展示多个过程图表。
6. 展示运行日志。
7. 展示当前最优方案信息。
8. 展示约束满足情况。
9. 展示预估结果摘要。
10. 展示操作区：查看评价结果、保存当前方案、终止计算。
11. 右侧展示功能图标栏。
12. 支持 mock 进度动态变化。
13. 点击“查看评价结果”进入评价决策页面。
```

当前阶段不实现：

```text
1. 不调用真实后端接口。
2. 不连接数据库。
3. 不调用 MATLAB。
4. 不读取真实 MATLAB 输出文件。
5. 不接真实 WebSocket。
6. 不做真实任务终止。
7. 不做真实保存方案。
8. 不做真实计算资源监控。
```

## 4. 页面整体布局

过程透明页面采用：

```text
顶部系统栏 + 方案情景选择区 + 过程展示状态栏 + 左监测趋势/右详情分栏区 + 底部辅助信息区 + 右侧功能图标栏
```

页面结构如下：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部系统栏：系统名称 / 当前页面 / 当前时间 / 状态              │
├──────────────────────────────────────────────────────────────┤
│ 方案情景选择：方案一防洪优先 / 方案二发电优先 / 方案三生态优先  │       
├──────────────────────────────────────────────────────────────┤ 
│ 任务状态 / 调度周期 / 已运行时间 / 剩余时间 / 进度 │                  │ 图标    │
├────────────────────────────────────────────┬───────┬─────────┤  
│ ┌─ 算法收敛曲线 ────────────────────────┐  │ ┌─ Tab: 水位过程线 ──┐ │ 图标    │
│ └──────────────────────────────────────┘  │ │                    
│ ┌─ 最优目标值变化趋势 ──────────────────┐  │ │    龙羊峡/刘家峡     │ │ 图标    │
│ └──────────────────────────────────────┘  │ │    水位过程曲线      
│ ┌─ 种群多样性变化 ──────────────────────┐  │ ├─ Tab: 下泄流量过程线─┤ │ 图标    │
│ └──────────────────────────────────────┘  │ ├─ Tab: 出力过程线 ──┤ │        │
├────────────────────────────────────────────┴───────┴─────────┤
│ 底部辅助区：运行日志 / 最优方案 / 约束满足 / 预估摘要 / 操作   │
└──────────────────────────────────────────────────────────────┘
```

布局要求：

```text
1. 页面为 16:9 宽屏布局。
2. 顶部方案情景选择区横向排列。
3. 中部采用"左右"分栏布局：
   - 左侧固定展示 3 个监测图表（算法收敛曲线、最优目标值变化趋势、种群多样性变化）
   - 右侧通过 Tab 切换展示水库过程曲线（水位、下泄流量、出力）
4. 底部辅助信息区横向分区展示。
5. 右侧功能栏只显示资源占用的相关图标，不展开大面板。
6. 页面信息较多，但要保持分区清晰、边界明确。
7. 图表卡片大小一致，避免重叠。
8. 不做浅色普通后台风格。
```

## 8. 中部过程图表区（左监测趋势 + 右详情 分栏布局）

中部过程图表区是页面核心区域，采用**左监测趋势 + 右详情**分栏布局。

### 布局结构

```text
┌──────────────────────────────┬────────────────────────────────┐
│                              │                                │
│ ┌ 算法收敛曲线 ────────────┐  │ ┌ Tab: 水位过程线 ──────────┐   │
│ │                          │  │ │  龙羊峡水位 + 刘家峡水位   │   │
│ └──────────────────────────┘  │ │                            │   │
│ ┌ 最优目标值变化趋势 ──────┐  │ ├ Tab: 下泄流量过程线 ──────┤   │
│ │  总目标/防洪/发电/生态    │  │ │  龙羊峡下泄 + 刘家峡下泄   │   │
│ └──────────────────────────┘  │ │                            │   │
│ ┌ 种群多样性变化 ──────────┐  │ ├ Tab: 出力过程线 ──────────┤   │
│ │                          │  │ │  龙羊峡出力 + 刘家峡出力   │   │
│ └──────────────────────────┘  │ └────────────────────────────┘   │
└──────────────────────────────┴────────────────────────────────┘
```

### 左侧

左侧固定展示 3 个监测图表，纵向堆叠，每个占等高：

#### 8.1 算法收敛曲线

- **标题**：算法收敛曲线
- **类型**：ECharts 折线图 + 面积图
- **横轴**：迭代次数（0 ~ 500）
- **纵轴**：适应度值（对数）
- **图例**：当前最优适应度
- **颜色**：蓝色 `#00afff`，下方半透明面积填充
- **展示要求**：曲线整体下降，表示算法逐步收敛

#### 8.2 最优目标值变化趋势

- **标题**：最优目标值变化趋势
- **类型**：ECharts 多折线图
- **横轴**：迭代次数
- **纵轴**：目标值
- **图例**：总目标值、防洪目标、发电目标、生态目标
- **颜色**：蓝 `#00afff` / 绿 `#00e5a0` / 黄 `#ffaa00` / 红 `#ff6b6b`
- **展示要求**：4 条曲线同时展示，观察多目标优化过程

#### 8.3 种群多样性变化

- **标题**：种群多样性变化
- **类型**：ECharts 折线图
- **横轴**：迭代代数
- **纵轴**：多样性指数
- **颜色**：紫色 `#b37feb`
- **展示要求**：曲线逐步下降，辅助说明算法搜索过程

### 右侧

右侧通过 **el-tabs** 切换 3 个图表 Tab，每个 Tab 中合并展示龙羊峡和刘家峡的过程曲线：

#### 8.4 Tab 1：水位过程线

- **横轴**：日期（05-16 ~ 05-26）
- **纵轴**：水位（m）
- **系列线**：
  - 龙羊峡最优方案 / 龙羊峡入库预报 / 龙羊峡历史运行
  - 刘家峡最优方案 / 刘家峡入库预报 / 刘家峡历史运行
- **颜色**：龙羊峡蓝青系、刘家峡绿系

#### 8.5 Tab 2：下泄流量过程线

- **横轴**：日期
- **纵轴**：流量（m³/s）
- **系列线**：
  - 龙羊峡最优下泄 / 龙羊峡调度下泄 / 龙羊峡最小下泄
  - 刘家峡最优下泄 / 刘家峡调度下泄 / 刘家峡最小下泄
- **颜色**：最优蓝、调度黄、最小红

#### 8.6 Tab 3：出力过程线

- **横轴**：日期
- **纵轴**：出力（MW）
- **系列线**：
  - 龙羊峡最优出力 / 龙羊峡调度出力 / 龙羊峡装机容量（虚线）
  - 刘家峡最优出力 / 刘家峡调度出力 / 刘家峡装机容量（虚线）
- **颜色**：最优蓝、调度黄、装机容量红虚线

### 图表通用要求

```text
1. 所有图表遵循全局 ECharts 规范：标题、单位、图例、tooltip。
2. 适配深色主题：tooltip 深蓝背景，坐标轴文字浅灰蓝，网格虚线低透明度。
4. 右面板使用单个 ECharts 实例，Tab 切换时通过 setOption 更新数据。
5. 全部数据来自 src/mock/processTransparent.ts。
```

## 12. 页面交互规则

### 12.1 方案切换

```text
1. 默认选中“方案一：防洪优先”。
2. 点击其他方案后切换 activeScenarioId。
3. 中部图表和底部摘要同步切换 mock 数据。
4. 不重新计算。
```

### 12.2 进度模拟

```text
1. 当前阶段可以使用前端定时器模拟进度增长。
2. 进度增长时，已运行时间、预计剩余时间可同步变化。
3. 进度到 100% 后，任务状态变为“已完成”。
4. 不接真实 WebSocket。
```

### 12.3 图表交互

```text
1. 所有图表支持 tooltip。
2. 图例支持显示隐藏。
3. 图表右上角全屏图标当前阶段只做 UI。
4. 不做真实图表导出。
```

### 12.4 查看评价结果

```text
1. 点击“查看评价结果”跳转 /evaluation-decision。
2. 可传递当前方案 ID 或 taskId 到 Pinia。
3. 不调用接口。
```

### 12.5 保存当前方案

```text
1. 点击后提示“当前方案已保存”。
2. 当前阶段不写入数据库。
3. 不保存真实案例库。
```

### 12.6 终止计算

```text
1. 点击后弹出确认框。
2. 确认后可将 mock 状态改为“已终止”。
3. 不终止真实任务。
```

## 13. 组件拆分建议

建议页面组件：

```text
src/views/process-transparent/ProcessTransparentView.vue
```

开发原则：

```text
1. 先创建 mock 数据文件，再逐步开发各组件。
2. 每个组件独立开发，通过 props 接收数据。
```
