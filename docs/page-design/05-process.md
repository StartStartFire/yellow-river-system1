# 过程透明页面图表区布局改版需求

## 修改目标

重新设计「过程透明」页面中部图表展示区域，强化“算法优化过程”与“水库运行响应过程”的对应关系。

整体采用 **左右双栏布局（40% : 60%）**。

- 左侧：展示算法优化过程
- 右侧：展示水库运行响应过程
- 页面风格保持现有深色科技风、水利调度监控风格不变

# 设计原则

1. 左侧只展示算法过程（为什么得到该结果）。
2. 右侧只展示运行响应（结果产生了什么影响）。
3. 强化“算法优化 → 调度结果”的透明化逻辑链。
4. 不再同时展示龙羊峡和刘家峡所有图表，避免信息过载。
5. 通过 Tab 切换实现单库深度分析。
