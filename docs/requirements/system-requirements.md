# 黄河上游水库群调度系统详细功能需求文档

---

## 1. 文档概述

### 1.1 编制目的

本文档用于明确“黄河上游水库群调度系统”的建设目标、功能范围、模块边界、页面结构、交互流程、数据规则，为后续原型细化、UI 设计、前端开发、后端开发、模型调用提供依据。

### 1.2 文档范围

本文档覆盖以下内容：

- 系统建设背景与总体定位
- 系统功能架构与模块分类
- 各功能模块的页面级、功能级、交互级需求
- 核心业务流程与模块联动关系
- 数据来源、数据流转和数据边界
- 页面状态、按钮控制、提示语与验收要点

### 1.3 系统定位

本系统面向黄河上游水库群联合调度科研分析、模拟推演、过程展示、方案评价和成果复用场景，主要服务于科研人员、项目汇报人员和管理决策人员。

系统定位为：

- **科研分析平台**：支撑不同调度周期、不同水库组合、不同模型算法和不同场景约束下的调度方案研究。
- **过程透明平台**：展示模型运行过程、算法迭代过程、关键中间结果和计算资源占用状态，降低“黑箱模型”带来的理解成本。
- **可视化汇报平台**：通过地图、曲线、雷达图、桑基图、帕累托曲线、报表等形式，形成适合科研演示和领导汇报的可视化成果。
- **成果复用平台**：通过案例库沉淀典型调度结果，支持历史案例查看、结果复现。

### 1.4 核心约定

1. 系统不生成、不下发真实调度指令，页面中的“调度指令”仅用于历史展示、对比分析和科研模拟。
2. 系统中的“辅助决策”仅作为人工分析参考，不自动形成业务结论。
3. 本期重点建设功能需求、页面展示、流程联动和成果可视化，不深化外部接口对接细节。
4. 模型计算由外部 MATLAB 模型实现，系统侧主要负责参数配置、任务触发、过程展示和结果承接。
5. 本期不考虑多任务并发、复杂排队调度和多用户协同编辑场景。
6. 全站统一采用“深色写实科技风、中国智慧水利科研平台风格”，页面应适配 16:9 宽屏和 1920×1080 及以上分辨率。

## 2. 项目概述

### 2.1 建设背景

黄河上游龙羊峡、刘家峡、公伯峡、积石峡、青铜峡等骨干水库承担防洪、供水、发电、生态、冲沙等多目标综合调度任务。在科研分析和成果汇报过程中，常见问题包括：数据来源分散、模型配置过程不直观、计算过程缺少透明展示、方案评价结果难以对比、历史成果难以复用、报表输出不统一等。

因此，需要建设一个集**基础数据展示、调令对比分析、模型配置、过程透明、评价决策、案例复现、报表统计**于一体的综合业务平台，提升黄河上游水库群联合调度研究的系统性、可解释性和演示效果。

### 2.2 建设目标

1. 建立水库群历史基础数据、运行数据、调令数据和案例成果的统一展示入口。
2. 支持中长期、短期、实时三类调度周期下的模型数据上传、基础配置、模型算法配置、场景约束配置和计算任务提交。
3. 实现模型运行全过程可视化，展示任务状态、迭代进度、过程曲线、约束满足情况和计算资源占用状态。
4. 支持调度结果的多方案评价、单方案决策分析、目标满足情况展示和方案导出。
5. 建设案例库，实现历史案例、检索、查看和快速复现。
6. 支持逐月、逐年报表统计与 Excel 导出，满足科研汇报和成果归档需求。

### 2.3 系统模块

系统包含八个一级模块：

1. 首页
2. 基础数据
3. 水调水情
4. 模型配置
5. 过程透明
6. 评价决策
7. 案例库
8. 报表统计

## 3. 总体架构与模块边界

### 3.1 模块分类

系统模块划分为两类：独立展示模块和核心联动模块。

| 模块分类 | 模块名称 | 核心定位 | 运行特性 |
|---|---|---|---|
| 独立展示模块 | 首页 | 全局态势总览与系统入口 | 独立调用历史数据，仅展示，不依赖其他模块 |
| 独立展示模块 | 基础数据 | 水库基础信息、断面、水情过程、工情信息展示 | 独立调用历史静态数据和运行数据，仅查询展示，不支持上传修改 |
| 独立展示模块 | 水调水情 | 实际运行数据与调令数据对比分析 | 独立查询历史运行与调令数据，不参与模型计算流程 |
| 独立展示模块 | 案例库 | 历史调度案例、检索与复现 | 独立调用案例数据，复现时不重新计算 |
| 独立展示模块 | 报表统计 | 历史运行数据与成果统计报表 | 独立生成统计报表，支持 Excel 导出 |
| 核心联动模块 | 模型配置 | 调度任务全参数配置和模型数据上传 | 作为计算流程起点，提交后进入过程透明模块 |
| 核心联动模块 | 过程透明 | 模型计算过程监控和中间结果展示 | 接收模型配置任务，完成后联动评价决策模块 |
| 核心联动模块 | 评价决策 | 调度结果评价、单方案决策和成果输出 | 接收过程透明计算结果，成果可保存至案例库 |

### 3.2 数据边界

1. **历史基础数据**：包括水库特征、断面参数、水情历史数据、工情运行数据，供首页、基础数据、水调水情、报表统计等独立展示模块读取。
2. **模型上传数据**：由用户在模型配置模块的“模型数据”步骤上传，用于本次模型计算，不依赖基础数据模块。
3. **计算过程数据**：由模型运行过程产生，包括迭代日志、中间目标值、过程曲线、约束满足情况、资源占用状态等，供过程透明模块展示。
4. **评价结果数据**：由模型计算结果和评价分析生成，包括指标结果、方案对比、单方案过程线、水量分配等，供评价决策模块展示。

### 3.3 核心联动流程

核心联动模块按照以下流程执行：

```text
模型配置（模型数据 → 基础配置 → 模型算法 → 场景约束 → 配置汇总）
    → 过程透明（任务运行监控、过程曲线、日志、资源监控）
    → 评价决策（多方案评价、单方案决策、方案导出）
```

## 5. 全局页面规范

### 5.1 顶部导航栏

全站顶部导航栏统一展示：

```text
首页 / 基础数据 / 水调水情 / 模型配置 / 过程透明 / 评价决策 / 案例库 / 报表统计
```

导航要求：

- 当前所在模块高亮显示。
- 导航栏样式与最新 UI 原型保持一致，采用深色背景、蓝青色高亮、简洁分隔。
- 顶部状态区展示系统标题、当前时间、当前模式、调度状态或任务状态。

### 5.2 页面视觉风格

- 整体采用深蓝灰、蓝青色为主色调，辅以背景图 + 半透明毛玻璃面板，局部使用绿色、橙色、红色进行状态或风险强调。
- 页面采用写实科技风，不使用插画风、概念科幻风和过度装饰效果。
- 图表风格应贴近真实业务系统，支持图例、坐标轴、单位、悬浮提示和全屏查看。
- 避免将所有图表、指标和表格直接铺满页面，优先采用“核心摘要 + 标签页 + 折叠区 + 按需查看”的组织方式。
- 重点页面适配领导汇报和科研演示场景，信息层级清晰、模块边界明确、留白充足。

### 5.3 通用状态

| 状态 | 展示要求 |
|---|---|
| 加载中 | 显示 loading 动画和“数据加载中，请稍候……”提示 |
| 无数据 | 显示“当前筛选条件下暂无数据”占位 |
| 加载失败 | 显示“数据加载失败，请稍后重试”提示，并提供重试入口 |
| 运行中 | 展示动态进度、任务状态、已运行时间和预计剩余时间 |
| 已完成 | 任务进度固定为 100%，允许查看评价结果 |
| 已终止 | 显示终止原因，不允许进入评价结果，除非已有可用阶段性结果 |

## 6. 详细功能需求

## 6.1 首页模块

### 6.1.1 功能目标

首页作为系统默认入口，用于展示黄河上游水库群整体运行态势、水情监控、发电统计、过程曲线、预警信息和地图总览。

### 6.1.2 功能内容

1. **流域地图展示**
   - 展示黄河上游流域地形、水系和重点水库点位。
   - 标注龙羊峡、刘家峡、公伯峡、积石峡、青铜峡等重点水库。
   - 支持水库点位点击弹窗，展示水库名称、当前水位、入库流量、出库流量、库容等摘要信息。
   - 支持图层控制，如水系、流域边界、水库点位、预警图层等。

2. **水情监控**
   - 按水库展示入库流量、出库流量、坝前水位、尾水位、库容、机组过流流量。
   - 采用统一面板 + 发光分割线布局，突出当前值、单位和变化趋势。

3. **发电统计**
   - 展示日发电量、月发电量、年发电量。
   - 支持数值卡片和简要趋势图。

4. **过程曲线**
   - 展示水位过程曲线。
   - 展示负荷过程曲线，支持有功/无功切换。

5. **预警信息**
   - 展示红、橙、黄、蓝四级预警。
   - 支持预警时间、预警类型、水库对象、简要说明展示。

### 6.1.3 页面结构

首页采用“顶部状态栏 + 左中右三栏”结构：

- 左侧：水情监控卡片、发电统计卡片。
- 中部：黄河上游流域地图、水库点位、图层控制。
- 右侧：水位过程曲线、负荷过程曲线、预警信息面板。

### 6.1.4 数据特性

首页独立调用历史运行数据和实时展示数据，不依赖模型配置、过程透明和评价决策模块，不支持数据上传和修改。

---

## 6.2 基础数据模块

### 6.2.1 功能目标

基础数据模块用于以水库对象为核心，展示水库静态属性、断面示意、水情过程和工情运行信息。该模块仅提供历史基础数据和运行数据查询展示，不承担模型数据上传、Excel 文件管理、数据校验和数据修改职责。

### 6.2.2 页面结构

基础数据页面采用“左侧水库列表 + 右侧多标签详情区”结构。

- 左侧：水库对象列表，展示龙羊峡、刘家峡等水库名称和运行状态。
- 右侧顶部：选中水库的 4 项核心指标卡片。
- 右侧主体：多标签详情区，包括“基础信息 / 水库断面 / 水情过程 / 工情信息”。

页面要求：

- 右侧内容卡片顶部不再重复显示“水库信息”“模型数据”等冗余标题。
- “模型数据”不属于基础数据模块，应统一放入模型配置模块第一步。
- 页面不展示文件上传、模板下载、数据校验记录、数据变更记录等操作。

### 6.2.3 功能内容

#### 1. 水库列表导航

- 展示水库名称、简要状态、是否重点水库等信息。
- 支持点击切换水库对象。
- 当前选中水库高亮显示。

#### 2. 核心指标展示

选中水库后，顶部展示：

| 指标 | 说明 |
|---|---|
| 当前水位 | 展示坝前水位或上游水位，单位 m |
| 入库流量 | 当前入库流量，单位 m³/s |
| 出库流量 | 当前出库流量，单位 m³/s |
| 蓄水量 | 当前库容或蓄水量，单位 亿 m³ |

指标卡片支持展示较昨日变化值和趋势箭头。

#### 3. 基础信息标签页

展示水库静态基础属性，包括：

- 水库名称、水库编码、所属流域、所在水系
- 坝型、坝高、坝顶高程、坝顶长度、最大坝高
- 装机容量、机组台数、单机容量
- 正常蓄水位、汛限水位、死水位、设计洪水位、校核洪水位
- 调度规则摘要、生态下泄要求、发电约束规则

#### 4. 水库断面标签页

以断面示意图方式展示水库特征水位和坝体信息，应标注：

- 校核洪水位
- 设计洪水位
- 正常蓄水位
- 汛限水位
- 死水位
- 当前水位
- 坝顶高程、坝顶长度、最大坝高
- 当前入库流量、当前出库流量

断面图应避免过度拥挤，关键高程使用水平线和标签标注。

#### 5. 水情过程标签页

展示水库水位、入库流量、出库流量历史过程线，支持：

- 时间范围筛选
- 曲线悬浮查看数据点
- 图例开关
- 多指标切换

#### 6. 工情信息标签页

展示水库机组运行状态、闸门开度、泄洪工况等工情数据，包括：

- 机组状态：运行、停机、检修等
- 闸门开度
- 泄洪流量
- 发电流量
- 当前出力

### 6.2.4 数据特性

基础数据模块从统一数据层读取历史静态数据和运行数据，仅提供查询展示，不支持上传、修改、删除和校验操作。基础数据模块与模型配置模块的数据相互独立。

## 6.3 水调水情模块

### 6.3.1 功能目标

水调水情模块用于展示实际运行数据与调度指令数据之间的对比关系，帮助用户分析调令执行效果和运行偏差。

### 6.3.2 页面结构

页面采用“顶部筛选区 + 中部主图表区 + 摘要说明区”结构。

- 顶部筛选区：时间范围、水库对象。
- 中部主图表区：重点展示调令数据与实际运行数据的对比曲线。
- 摘要说明区：展示偏差摘要、最大偏差、平均偏差、异常时段说明。

页面要求：

- 不设置过多指标卡片，避免形成密集数据大屏。
- 重点突出水位、流量、出力等调令执行效果对比。

### 6.3.3 功能内容

1. **条件筛选**
   - 支持时间范围筛选。
   - 支持水库对象筛选。

2. **数据对比**
   - 实际入流与预报入流对比。
   - 实际水位与调令水位对比。
   - 实际出力与调令出力对比。
   - 实际出流与历史调令、未来调令对比。

3. **可视化分析**
   - 折线图展示目标值和实际值。
   - 支持图例开关、悬浮提示和全屏查看。

### 6.3.4 数据特性

水调水情模块独立调用历史运行数据和调令数据，仅用于查询与对比展示，不参与模型计算流程。

## 6.4 模型配置模块

### 6.4.1 功能目标

模型配置模块用于完成模型计算任务的前置配置，包括模型数据上传、基础调度信息、模型算法参数、场景约束和配置汇总提交。该模块是核心联动流程的起点。

### 6.4.2 页面步骤

模型配置模块采用顶部流程导航，最新页面步骤统一为六步：

```text
调度场景 → 调度主体 → 模型数据 → 模型算法 → 场景配置 → 配置汇总
```

要求：

- 当前步骤高亮显示。
- 支持上一步、下一步、保存草稿。
- 支持已完成步骤回退查看或修改。
- 点击“一键运行”后，配置进入只读状态，并跳转过程透明模块。

### 6.4.3 Step 1：调度场景

#### 功能说明

调度场景页面用于选择调度周期和场景子选项，决定后续的模型算法范围和调度目标预设。

#### 页面结构

- 3 大场景卡片横向排列：多年的中长期调度 / 年内关键期调度 / 实时调度
- 每个卡片包含 SVG 图标 + 标题 + 描述 + 子选项 radio 列表
- 选中子选项后自动联动调度目标到后续步骤

#### 场景分类

| 场景大类 | 子选项 | 联动调度目标 |
|---|---|---|
| 多年的中长期调度 | 多目标调度、防洪调度、凌汛调度、供水调度 | 随子选项自动预设 |
| 年内关键期调度 | 泥沙期调度、凌汛泥沙期、断面达标、河段达标 | 随子选项自动预设 |
| 实时调度 | 多能互补调度 | 随子选项自动预设 |

### 6.4.4 Step 2：调度主体

#### 功能说明

调度主体页面用于设置调度时间范围、时间步长、调度频率和水库选择。

#### 字段定义

| 字段名 | 控件 | 说明 |
|---|---|---|
| 调度起止时间 | 日期选择器 | 设定计算时段起点和终点 |
| 时间步长 | 下拉框 | 每日 / 每旬 / 每月（受场景约束过滤） |
| 调度频率 | 下拉框 | 每月一次 / 每旬一次 / 每周一次 / 不限制 |
| 水库组合 | 预设卡片 + 弹窗多选 | 龙刘组合、龙刘黑组合、全部水库、更多组合 |

#### 场景约束

- 中长期调度：≥1年≤5年，步长仅每旬/每月
- 关键期调度：≤1年（同一年内），步长仅每旬/每月
- 实时调度：≤31天，步长仅每日（锁定）

### 6.4.5 Step 3：模型数据

#### 功能说明

模型数据页面用于上传和展示本次模型计算所需输入数据。该步骤独立于基础数据模块，不从基础数据模块直接取数。

#### 页面结构

### 6.4.6 Step 4：模型算法

#### 功能说明

模型算法页面用于选择与调度场景匹配的模型和算法，配置算法参数，同时展示调度目标和约束条件。

#### 页面结构

- 左侧：模型选择 + 算法选择 + 参数设置
- 右侧：调度目标卡片（从 Step 1 联动预填，可增删）+ 约束条件摘要（弹窗编辑）

#### 模型与算法映射

| 调度场景 | 可选模型 | 可选算法 |
|---|---|---|
| 中长期 | 多目标协同胁迫模型 | PSO、NSGA-II |
| 关键期 | 多目标优化模型 | PAEM |
| 实时 | 水沙实时调度模型 | NSGA-III |

#### 选择控制

- 不符合当前调度周期的模型应置灰禁用，不允许选择。
- 模型选择后，算法下拉框仅展示该模型支持的算法。
- 切换算法后，参数面板自动更新。

#### 参数展示要求

参数区应采用“参数卡片 + 滑块/输入框 + 简要说明”的方式展示。每个参数应说明“参数较高会怎样、参数较低会怎样”。

| 参数名 | 字段标识 | 默认值 | 范围 | 趋势说明 |
|---|---|---:|---|---|
| 种群规模 | populationSize | 200 | 50-1000 | 越大搜索更充分、结果更稳定，但计算耗时增加；越小计算更快，但易遗漏优良解 |
| 迭代次数 | iterationCount | 500 | 100-2000 | 越大收敛更充分，但运行时间更长；越小速度快，但可能未充分收敛 |
| 交叉概率 | crossoverRate | 0.9 | 0-1 | 越高探索能力更强；越低解集变化较慢 |
| 变异概率 | mutationRate | 0.10 | 0-1 | 越高跳出局部最优能力更强，但过高会导致结果波动；越低稳定但探索不足 |
| 精英保留比例 | eliteRate | 0.05 | 0-0.2 | 越高保留优良解更多，但可能降低多样性；越低多样性更高但优良解易丢失 |
| 随机种子 | randomSeed | 200 | 1-9999 | 用于复现实验结果 |

### 6.4.7 Step 5：场景配置

#### 功能说明

场景配置页面用于配置来水、调水、生态、发电、冲沙和水位边界等业务条件，形成具体计算场景。

#### 字段定义

| 字段名 | 字段标识 | 控件 | 可选值/示例 | 说明 |
|---|---|---|---|---|
| 场景名称 | scenarioName | 文本/自动生成 | 自动生成或手动输入 | 用于识别方案场景 |
| 西线调水 | westRoute | 下拉/单选 | 无 / 上线 / 下线 / 上下线同引 | 表示是否考虑西线调水 |
| 骨干工程 | backboneProject | 开关 | 是 / 否 | 是否考虑黑山峡等骨干工程情景 |
| 冲沙流量 | sedimentFlow | 下拉/输入 | 1800 / 2000 m³/s | 冲沙约束参数 |
| 水位约束 | levelConstraint | 选择/表格 | 上限、下限、汛限水位 | 控制运行边界 |
| 生态约束 | ecoConstraint | 选择/表格 | 最小生态流量 | 控制生态下泄要求 |
| 发电约束 | powerConstraint | 选择/表格 | 出力上下限 | 控制发电目标与机组运行边界 |

#### 约束校验

- 关键约束应显示“已配置/未配置”状态。
- 不完整或冲突的约束项应在右侧校验区提示。
- 允许用户在提交前查看约束摘要。

### 6.4.8 Step 6：配置汇总

#### 功能说明

配置汇总页面用于展示本次任务的模型数据、调度主体、模型算法、场景配置和参数设置，用户确认后提交计算。

#### 页面内容

- 配置摘要表
- 模型数据清单
- 参数摘要
- 场景约束摘要
- 校验结果
- 操作按钮：上一步、保存草稿、开始计算

#### 提交逻辑

1. 用户点击“开始计算”。
2. 系统校验模型数据、基础配置、模型算法和场景约束完整性。
3. 校验通过后生成任务 ID。

## 7. 页面交互与状态流转

### 7.1 模型计算主流程

1. 用户进入模型配置模块。
2. 在“模型数据”步骤上传并校验模型输入数据。
3. 在“基础配置”步骤选择调度周期、调度时间、水库组合和调度目标。
4. 在“模型算法”步骤选择模型、算法和参数。
5. 在“场景约束”步骤配置来水、调水、水位、生态、发电、冲沙等约束。
6. 在“配置汇总”步骤确认全部配置并点击“开始计算”。
7. 系统生成任务 ID，并跳转过程透明模块。
8. 过程透明模块展示任务运行状态、过程曲线、日志和资源监控。
9. 任务完成后，用户进入评价决策模块。
10. 用户进行多方案评价、单方案决策、方案导出。

### 7.2 独立展示模块流程

| 模块 | 流程 |
|---|---|
| 首页 | 进入页面 → 加载历史运行数据 → 展示总体态势 |
| 基础数据 | 进入页面 → 选择水库 → 切换标签页 → 查看基础信息/断面/水情/工情 |
| 水调水情 | 进入页面 → 设置筛选条件 → 查询 → 展示实际与调令对比 |
| 案例库 | 进入页面 → 检索案例 → 查看详情 → 复现历史结果 |
| 报表统计 | 进入页面 → 设置报表条件 → 查询 → 预览报表 → 导出 Excel |

### 7.3 按钮控制

| 场景 | 控制要求 |
|---|---|
| 模型配置中 | 字段可编辑，支持保存草稿和步骤跳转 |
| 模型数据未通过校验 | 不允许进入配置汇总提交计算 |
| 点击开始计算后 | 配置内容锁定，只读展示 |
| 过程透明运行中 | 可终止计算，可查看过程，不可进入最终评价结果 |
| 过程透明完成后 | 可查看评价结果，可保存当前方案 |
| 评价决策页面 | 可切换方案、导出方案 |
| 案例复现 | 只读展示历史结果，不重新计算 |
| 报表统计 | 只读展示，支持查询、重置和导出 |

## 9. 数据设计与流转规则

### 9.1 数据来源

| 数据来源 | 数据内容 | 使用模块 |
|---|---|---|
| 历史基础数据 | 水库特征、断面参数、水情历史数据、工情运行数据 | 首页、基础数据、水调水情、报表统计 |
| 用户上传数据 | 模型计算所需 Excel 文件和输入数据 | 模型配置 |
| 计算过程数据 | 迭代日志、中间目标值、过程曲线、资源监控数据 | 过程透明 |
| 评价结果数据 | 方案指标、评价图表、单方案过程线、水量流向图 | 评价决策 |
| 案例成果数据 | 已保存方案、配置摘要、结果指标和图表快照 | 案例库 |

### 9.2 数据流转规则

1. 独立展示模块直接读取统一数据层，仅查询展示，不写入和修改数据。
2. 基础数据模块不向模型配置模块传递数据。
3. 模型配置模块的模型数据由用户上传文件获取。
4. 模型配置提交后生成任务数据，传递给过程透明模块。
5. 过程透明模块生成过程数据和最终计算结果，传递给评价决策模块。
