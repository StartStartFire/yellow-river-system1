# 梯级水库调度规则精简汇总

> 基于 `evaluate_objective_NSGA2.m` / `evaluate_objective.m` 代码逆向提取
> 水库：龙羊峡（龙头）→ 刘家峡（反调节）

---

## 1. 水量平衡（物理核心）

**规则**：时段末库容 = 时段初库容 + (入库 - 出库) × 时段换算系数

```
龙羊峡: Vlong(i,j+1) = Vlong(i,j) + (LONG_IN - Qlongout) × xishu(j)
刘家峡: Vliu(i,j+1)  = Vliu(i,j)  + (Qlongout + LONG_LIU - Qliuout) × xishu(j)
```

> 两库串联：刘家峡入库 = 龙羊峡出库 + 龙刘区间来水

---

## 2. 水位/库容边界约束

| 水库 | 死库容（下限） | 满库容（上限） | 处理方式 |
|------|-------------|-------------|---------|
| 龙羊峡 | 42.63 亿m³ | 242.9 亿m³ | **截断**：越界则强制设为边界值，反算出库流量 |
| 刘家峡 | 6.223 亿m³ | 39.93 亿m³ | **截断**：同上 |

> 此外，遗传算子产生的子代水位由 `genetic_operator.m` 裁剪到 `[VarMin, VarMax]` 范围

---

## 3. 防凌期调度（11月~次年3月，时段索引 j=9~13）

| 规则 | 内容 |
|------|------|
| 龙羊峡出库 | 固定 **550 m³/s** |
| 龙羊峡库容 | 由水量平衡反算，若越界则截断并回写水位 |
| 刘家峡防凌流量上限 | 11月 **610** → 12~3月 **420** m³/s |
| 超出处理 | 优先刘家峡自蓄 → 蓄满则龙羊峡协同蓄水 → 都蓄满才允许超限排放 |

---

## 4. 生态流量约束（龙羊峡）

| 条件 | 动作 |
|------|------|
| 龙羊峡出库 < **350** m³/s | 强制抬升至 **550** m³/s，反算库容和水位 |
| 龙羊峡出库 > **1050** m³/s | 强制压降至 **550** m³/s，反算库容和水位 |

---

## 5. 兰州断面需水约束

**规则**：刘家峡下泄必须满足兰州断面需水（扣除刘兰区间来水）

```
if Qliuout < LAN - LIU_LAN:
    Qliuout = LAN - LIU_LAN    # 强制抬升到需水值
```

此外，刘家峡出库的硬约束窗口：
- 下限 **350** m³/s → 低于时按兰州需水下泄
- 上限 **1200** m³/s（最大过机流量）→ 超出时按兰州需水下泄

---

## 6. 装机容量约束（截断 + 弃水）

| 电站 | 装机上限 | 处理方式 |
|------|---------|---------|
| 龙羊峡 | **128** 万kW | 超限截断，多余水量算作弃水 |
| 刘家峡 | **122.5** 万kW | 超限截断，多余水量算作弃水 |
| 下游12座梯级 | 各电站固定值（16~280万kW） | 超限截断，不计弃水 |

---

## 7. 保证出力约束（迭代修正）

当出力低于保证出力且库容充足时，**逐次增大出库流量**（步长10 m³/s）以提升出力：

| 电站 | 保证出力 | 特枯年折扣 |
|------|---------|-----------|
| 龙羊峡 | **58.7** 万kW | P≥0.75 时按 8折 = 46.96 万kW |
| 刘家峡 | **40** 万kW | P≥0.75 时按 8折 = 32 万kW |

**来水频率判断**：`P(i) < 0.75` 为非特枯年，否则为特枯年  
**最大迭代次数**：100 次，仍未满足则用最后一次结果

---

## 8. 调水调沙规则（7月下旬~8月上旬，时段 j=3~4）

**触发条件**（必须同时满足）：
1. 来水偏丰及以上：`P(i) ≤ 0.80`
2. 龙羊峡库容充裕：`Vlong(i,j) > 85` 亿m³
3. 刘家峡库容充裕：`Vliu(i,j) > 18` 亿m³

**执行动作**：

| 操作 | 龙羊峡 | 刘家峡 |
|------|-------|-------|
| 出库流量 | **1350** m³/s（最小调沙流量） | **Q_sediment - LIU_LAN**（使总流量达1800~2200） |
| 电站出力 | 按装机满发 **128** 万kW | 按装机满发 **122.5** 万kW |
| 弃水 | 超出1050部分弃水 | 超出1200部分弃水 |

**标记**：调沙年 `f(i)=1`，累计 `k=k+1`

---

## 9. 10月预腾防凌库容

**时段 j=8（10月）**：
```
刘家峡出库 = 700 m³/s   # 强制大流量泄放，腾空库容迎接防凌期
```

---

## 10. 汛期水位趋势约束（种群初始化）

每年**前7个时段**（约7月~10月），两库水位应呈**上升趋势**：

```
若 水位(m) > 水位(m+1)，则 水位(m+1) = 水位(m) + rand(0, 2)
```

> 此规则仅在 `initialize_population.m` 中用于初始种群生成，进化过程中由截断机制间接维护

---

## 11. 年度起调水位衔接

每年末（j=20）将年末水位赋给下一年的起调水位：
```
LONG_Z_INI(i+1) = x(20 + (i-1)×20)    # 龙羊峡
LIU_Z_INI(i+1)  = x(20×Y + 20 + (i-1)×20)  # 刘家峡
```

> 第一年起调水位为固定值：龙羊峡 2580m，刘家峡 1720m

---

## 12. 防凌期两库协同蓄泄逻辑（详细）

当刘家峡出库超过防凌流量上限时，按以下优先级处理：

```
步骤1: 刘家峡能否自蓄？
  └─ 超量部分 ≤ 刘家峡剩余库容 → 全部存入刘家峡，出库压至防凌值
  └─ 否则 → 进入步骤2

步骤2: 刘家峡蓄满，龙羊峡协同
  ├─ 龙羊峡剩余库容 ≥ 多余水量 → 龙羊峡多蓄（减少出库），刘家峡出库压至防凌值
  └─ 龙羊峡也蓄满 → 两库均无力存蓄，允许超防凌流量排放
```

## 规则分类统计

| 类别 | 规则数 | 处理方式 |
|------|-------|---------|
| 物理约束 | 1 | 方程强制满足 |
| 硬边界截断 | 2 | 越界则截断+反算 |
| 强制赋值规则 | 5 | 固定值覆盖（防凌出库、生态、10月预腾） |
| 条件触发规则 | 2 | 调沙、保证出力 |
| 迭代修正规则 | 1 | 保证出力（逐步增大流量） |
| 协同蓄泄规则 | 1 | 两库联合调度（防凌超出处理） |
| 初始化规则 | 1 | 汛期趋势（仅初始化阶段） |
