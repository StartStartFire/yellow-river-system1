## 1. 模型概述

### 1.1 问题描述

本项目求解的是黄河上游 **龙羊峡—刘家峡梯级水库群** 的**长系列多目标优化调度**问题。

龙羊峡是黄河上游的龙头水库（多年调节），刘家峡是其下游的反调节水库。两库联合调度需同时满足**供水、发电、防凌、调水调沙、生态保障**五重任务，各目标相互冲突。

### 1.2 求解策略

采用 **NSGA-II**（非支配排序遗传算法）作为主算法进行多目标进化优化，搜索 Pareto 最优调度方案集。另有一个 **PAEM**（近似评价进化算法）变体（仅用于学术对比实验），通过在进化过程中引入局部随机扰动+近似评价来提升搜索效率。

### 1.3 空间范围

- **控制水库**：龙羊峡（龙头多年调节）、刘家峡（反调节）
- **梯级电站**：龙羊峡—刘家峡之间共计 **14 座**水电站，自上而下依次为：
  > 龙羊峡 → 拉西瓦 → 尼那 → 李家峡 → 积石峡 → 直岗拉卡 → 康扬 → 公伯峡 → 苏只 → 刘家峡 → 盐锅峡 → 八盘峡 → 小峡 → 大峡 → 青铜峡
- **供水断面控制点**：兰州断面

### 1.4 时间范围

- **水文年制**：每年从 7 月开始（水利年），至次年 6 月结束
- **长系列长度**：Y = 54 年（当前数据覆盖 **1970—2023 年**）
- **年时段划分**：每年 **20 个时段**（5~8 月分上中下旬，其余按月）

## 3. 决策变量

### 3.1 变量定义

决策变量向量 x 属于 R^V 表示两座水库在 Y 年 20 个时段的**时段末水位**序列：

```
V = 20 * Y * 2
```

| 索引范围 | 内容 | 维度 |
|---------|------|------|
| x_1 ~ x_(20Y) | 龙羊峡逐时段末水位 | 20Y |
| x_(20Y+1) ~ x_(40Y) | 刘家峡逐时段末水位 | 20Y |

**索引约定**：第 i 年第 j 时段的龙羊峡水位为：

```
x(j + (i-1)*20)
```

刘家峡对应时段的水位为：

```
x(20Y + j + (i-1)*20)
```

### 3.2 变量边界

每个决策变量有明确的物理边界，从数据文件读取：

```
VarMin_k <= x_k <= VarMax_k,  k = 1,...,V
```

- VarMin/VarMax 由 Excel 的 `LONGLIU-BOUND` 表生成
- 先取龙羊峡的 20 个时段边界，复制 Y 年 → 再取刘家峡的 20 个时段边界，复制 Y 年 → 拼接为长 V 的向量

### 3.3 起调水位

- **第一年起调水位**（默认值）：
  - 龙羊峡：**2580 m**
  - 刘家峡：**1720 m**
- 可通过全局变量 `LONG_Z_INI_VAL` / `LIU_Z_INI_VAL` 动态注入（Web 服务 `POST /run` 的 `initial_water_level_*` 参数），未设置时使用上述默认值
- **后续年起调水位** = 上年年末水位（j=20 时的水位值），形成序列耦合

## 4. 目标函数

### 4.1 目标 1：兰州断面多年平均缺水量最小化

**逐时段缺水量计算**：

```
Qshortage(i,j) = max( (LAN(i,j) - Qliuout(i,j) - LIU_LAN(i,j)) * xishu(j),  0 )
```

其中：
- LAN(i,j) = 第 i 年第 j 时段兰州断面总需水 (m^3/s)
- Qliuout(i,j) = 刘家峡出库流量 (m^3/s)
- LIU_LAN(i,j) = 刘家峡—兰州区间来水 (m^3/s)
- xishu(j) = 时段单位换算系数

**年总缺水量**：

```
T_Q_shortage(i) = sum_{j=1}^{20} Qshortage(i,j)
```

**多年平均**：

```
f_1 = (1/Y) * sum_{i=1}^{Y} T_Q_shortage(i)
```

**优化方向**：min f_1

### 4.2 目标 2：梯级电站群年均发电量最大化（转为最小化）

**逐时段梯级总发电量**：

```
Etii_longliu(i,j) = ( sum_{s=1}^{14} N_s(i,j) ) * t(j) * 24 * 10^(-4)
```

其中 N_s(i,j) 为第 s 座电站在第 i 年第 j 时段的出力（万 kW），t(j) 为时段天数。

**年总发电量**：

```
E_tiji(i) = sum_{j=1}^{20} Etii_longliu(i,j)
```

**目标函数**（取负以纳入最小化框架）：

```
f_2 = - (1/Y) * sum_{i=1}^{Y} E_tiji(i)
```

**优化方向**：min f_2（即最大化年均发电量）

### 4.3 目标 3：梯级调度系统总协同度最大化（M=3 时启用，转为最小化）

系统协同度由四个子系统的有序度构成：

```
H_tiji = geomean( max(0, [H_water, H_ele, H_sed, H_eco]) )
```

**目标函数**：

```
f_3 = -H_tiji
```

**优化方向**：min f_3（即最大化协同度）

#### 4.3.1 供水子系统有序度 H_water

**分项序参量**（逐年计算后多年平均）：

| 序参量 | 公式 | 权重 |
|-------|------|------|
| 工业生活用水保证率有序度 | d_water_rate1 = water_rate1 / 1 | 0.10 |
| 农业关键期总缺水有序度 | d_T_Q_shortage_agr = (26.63 - T_Q_shortage_agr) / 26.63 | 0.25 |
| 农业关键期缺水深度有序度 | d_T_Q_shortage1 = (1 - T_Q_shortage1) / 1 | 0.25 |
| 农业非关键期保证率有序度 | d_water_rate2 = water_rate2 / 1 | 0.20 |
| 农业非关键期总缺水有序度 | d_T_Q_shortage2 = (41.56 - T_Q_shortage2) / 41.56 | 0.20 |

> **注**：以上阈值（26.63、41.56 等）来源于规划文件中的需水极值，对应特定水平年情景。

**年供水有序度**：

```
h_water(i) = 0.10*d_water_rate1(i) + 0.25*d_T_Q_shortage_agr(i)
           + 0.25*d_T_Q_shortage1(i) + 0.20*d_water_rate2(i)
           + 0.20*d_T_Q_shortage2(i)
```

**多年有序度**：

```
H_water = (1/Y) * sum_{i=1}^{Y} h_water(i)
```

#### 4.3.2 发电子系统有序度 H_ele

| 序参量 | 公式 | 权重 |
|-------|------|------|
| 防凌期发电保证率有序度 | d_ele_rate1 = ele_rate1 / 1 | 0.20 |
| 防凌期平均出力有序度 | d_Ntiji_1 = Ntiji_1 / 1164 | 0.20 |
| 非防凌期发电保证率有序度 | d_ele_rate2 = ele_rate2 / 1 | 0.30 |
| 非防凌期平均出力有序度 | d_Ntiji_2 = Ntiji_2 / 1164 | 0.30 |

> **注**：1164 万kW 为 14 座梯级电站的总装机容量之和，431 万kW 为保证出力之和，均来源于规划文件。

**保证率计算**：统计时段内梯级总出力 > **431 万kW** 的时段占比。

**年发电有序度**：

```
h_ele(i) = 0.20*d_ele_rate1(i) + 0.20*d_Ntiji_1(i)
         + 0.30*d_ele_rate2(i) + 0.30*d_Ntiji_2(i)
```

**多年有序度**：

```
H_ele = (1/Y) * sum_{i=1}^{Y} h_ele(i)
```

#### 4.3.3 输沙子系统有序度 H_sed

仅在调沙年份（f(i)=1）计算：

| 序参量 | 公式 | 权重 |
|-------|------|------|
| 调沙流量有序度 | d_Q_sed = (Q_sed - 1800) / (2200 - 1800) | 0.60 |
| 调沙历时有序度 | d_t_sed = (t_sed - 10) / (30 - 10) | 0.40 |

**年输沙有序度**：

```
h_sed(i) = 0.60*d_Q_sed(i) + 0.40*d_t_sed(i)
```

**多年有序度**（考虑调沙频率）：

```
H_sed = 0.8 * sum(h_sed) / (k + 1e-8) + 0.2 * ((k/Y - 0.1) / (0.3 - 0.1))
```

其中 k 为长系列中实际调沙的年数，1e-8 为避免除零。

#### 4.3.4 生态子系统有序度 H_eco

| 序参量 | 公式 | 权重 |
|-------|------|------|
| 生态供水保证率有序度 | d_eco_rate = (eco_rate - 0.75) / (1 - 0.75) | 0.40 |
| 一次生态脉冲有序度 | 有脉冲则为 1，否则为 0 | 0.30 |
| 多次生态脉冲有序度 | d_L_eco = (L_eco - 1) / 5 | 0.30 |

**年生态有序度**：

```
h_eco(i) = 0.40*d_eco_rate(i) + 0.30*d_L_eco1(i) + 0.30*d_L_eco(i)
```

**多年有序度**：

```
H_eco = (1/Y) * sum_{i=1}^{Y} h_eco(i)
```

## 5. 约束条件与调度规则

### 5.1 水量平衡（核心物理约束）

```
龙羊峡: V_long(i,j+1) = V_long(i,j) + (Q_in(i,j) - Q_longout(i,j)) * xishu(j)
刘家峡: V_liu(i,j+1)  = V_liu(i,j)  + (Q_longout(i,j) + Q_LONG_LIU(i,j) - Q_liuout(i,j)) * xishu(j)
```

其中 Q_in 为龙羊峡入库，Q_LONG_LIU 为龙刘区间来水。

### 5.2 库容边界约束

```
龙羊峡: 42.63 亿m^3 <= V_long <= 242.9 亿m^3
刘家峡: 6.223 亿m^3 <= V_liu  <= 39.93 亿m^3
```

越界时截断至边界值，并反算出库流量。

### 5.3 水位边界约束

遗传算子产生的子代个体，水位值被强制裁剪到 [VarMin, VarMax] 范围内。

### 5.4 防凌期调度规则（j=9~13，即 11 月~次年 3 月）

龙羊峡固定出库：

```
Q_longout(i,j) = 550 m^3/s
```

刘家峡防凌流量上限：

```
Q_liuout(i,j) <= Qmin(j-8)

其中 Qmin = [610, 420, 420, 420, 420]
  j=9 (11月)  => 610
  j=10~13 (12月~3月) => 420
```

超出时按优先级处理：刘家峡自蓄 → 龙羊峡协同蓄 → 两库都蓄满才允许超限排放。

### 5.5 生态流量约束（龙羊峡）

```
350 <= Q_longout <= 1050 m^3/s
```

越界时强制拉回至 550 m^3/s，反算库容和水位。

### 5.6 兰州断面需水约束

```
Q_liuout(i,j) >= LAN(i,j) - LIU_LAN(i,j)
```

刘家峡出库同时受硬件约束：

```
350 <= Q_liuout <= 1200 m^3/s
```

### 5.7 装机容量约束

```
龙羊峡: N_long  <= 128 万kW
刘家峡: N_liu   <= 122.5 万kW
其余12座: 各站固定上限
```

超过装机容量的部分计为弃水流量。

### 5.8 保证出力约束

```
龙羊峡: N_long >= 58.7 万kW  (特枯年 P>=0.75 时 58.7*0.8=46.96)
刘家峡: N_liu  >= 40 万kW    (特枯年 P>=0.75 时 40*0.8=32)
```

不满足时以步长 10 m^3/s 逐次增大出库流量，最多迭代 100 次。

### 5.9 调水调沙规则（j=3~4，7 月下旬~8 月上旬）

**触发条件**（同时满足）：

```
P(i) <= 0.80  AND  V_long(i,j) > 85 亿m^3  AND  V_liu(i,j) > 18 亿m^3
```

**执行**：

```
Q_longout(i,j) = 1350 m^3/s
Q_liuout(i,j)  = Q_sediment - LIU_LAN(i,j)   (使总流量达1800~2200)
N_long(i,j)    = 128 万kW  (满发)
N_liu(i,j)     = 122.5 万kW  (满发)
```

目标调沙流量区间：1800 ~ 2200 m^3/s

> **注**：调沙流量区间（1800~2200 m^3/s）及龙羊峡调沙出库流量（1350 m^3/s）基于历史调度经验确定。

### 5.10 10 月预腾防凌库容（j=8）

```
Q_liuout(i,8) = 700 m^3/s
```

### 5.11 汛期水位趋势约束（种群初始化阶段）

每年前 7 个时段，水位应呈上升趋势，若不满足则修正：

```
若 x(20j+m) > x(20j+m+1)：
    x(20j+m+1) = x(20j+m) + U(0, 2)
```

## 6. 求解算法

### 6.1 NSGA-II（主算法）

```
输入: pop(种群大小), iterate(进化代数), M(目标数), Q_sediment(调沙流量), Pc(交叉概率，默认 0.9)
输出: Pareto 最优解集 chromosome + evaluating 评价指标矩阵 + plan_details 决策明细

1. 数据加载: load_data() -> 全局变量
2. 种群初始化: initialize_population()
   - 均匀随机生成 pop 个个体: x ~ U(VarMin, VarMax)
   - 汛期水位趋势修正
   - evaluate_objective() 精确评价每个个体
   - non_domination_sort_mod() 非支配排序
3. 进化循环: for gen = 1 to iterate
   a. 锦标赛选择: tournament_selection(pool=pop/2, tour=2)
      - 选择标准: rank 小优先 -> 拥挤距离大优先
   b. 遗传操作: genetic_operator()
      - SBX 交叉 (概率 Pc=入参，默认 0.9, eta_c=20)
      - 多项式变异 (概率 0.1, eta_m=20)
      - 子代裁剪到 [VarMin, VarMax]
   c. 子代评价: evaluate_objective_NSGA2()
      - 完整 Y*20 时段仿真
      - 水量平衡 -> 约束处理 -> 出力计算 -> 协同度
   d. 合并: intermediate = [parent; offspring]
   e. 非支配排序: non_domination_sort_mod()
      - 快速非支配排序 O(MN^2)
      - 拥挤距离计算
   f. 精英替换: replace_chromosome()
      - 按 rank 分层，同层按拥挤距离降序
      - 取前 pop 个个体
   g. 日志记录: 每代写入 NSGA2_progress.jsonl
   h. 回调推送: 每 10 代（含最后一代）调用 push_callback_data.m → POST /cb（progress 汇总指标 + process_data 过程数据）
4. 结束后逐个体调用 evaluate_objective_save_info()，生成 evaluating (pop×22) 与 plan_details（决策明细）
5. 返回最终种群 chromosome + evaluating + plan_details
```

### 6.2 PAEM 变体（学术对比实验算法）

> **说明**：PAEM（Approximate Evaluation Evolutionary Algorithm）是用于学术对比实验的算法变体，非生产主力算法。

PAEM 在 NSGA-II 框架基础上引入**近似评价机制**：

1. **对每个个体生成 K_mut 个变异版本**（当前配置 K_mut=50）：
   - 随机选择一年 i 和一个时段 j
   - 对该时段的决策变量执行单变量多项式变异（eta_m=20）
2. **早停计算**：当状态变量和决策变量的变化量小于 accuracy=[1e-4, 1e-4] 时提前结束该年计算
3. **非支配筛选**：原个体 + K_mut 个变异个体中选非支配解作为子代
4. **精确后评价**：进化结束后，对最终种群调用 evaluate_objective() 做精确评价
5. **误差分析**：比较近似解与精确解的目标函数值相对误差，评估近似精度

### 6.3 染色体数据结构

每行 chromosome 矩阵（维度 pop x (V + M + 2)）：

| 列范围 | 内容 | 说明 |
|-------|------|------|
| 1 ~ 20Y | 龙羊峡各年各时段水位 | 决策变量 |
| 20Y+1 ~ 40Y | 刘家峡各年各时段水位 | 决策变量 |
| V+1 ~ V+M | 目标函数值 f1, f2, [f3] | 评价结果 |
| V+M+1 | 非支配排序等级 rank | 1 = 第一前沿 |
| V+M+2 | 拥挤距离 | 越大越好 |

## 7. 梯级水电站出力计算

### 7.1 龙羊峡—刘家峡区间电站（受龙羊峡出库控制）

这些电站的出力公式为 N = K * H_k * (Q_longout + Q_LONG_LIU) / 10000，其中 H_k 为各站设计水头：

| 电站 | K | H_k (m) | 装机 (万kW) |
|------|---|---------|------------|
| 拉西瓦 | 8.3 | 205 | 280 |
| 尼那 | 8.0 | 15 | 16 |
| 李家峡 | 8.3 | 122 | 160 |
| 积石峡 | 8.3 | 66 | 102 |
| 直岗拉卡 | 8.2 | 12.5 | 19 |
| 康扬 | 8.2 | 18.7 | 30 |
| 公伯峡 | 8.3 | 99.3 | 150 |
| 苏只 | 8.3 | 16 | 22 |

### 7.2 刘家峡以下电站（受刘家峡出库控制）

N = K * H_k * (Q_liuout + Q_LIU_LAN) / 10000

| 电站 | K | H_k (m) | 装机 (万kW) |

### 7.3 龙羊峡、刘家峡电站

```
N_long = 8.6 * H_long * Q_longout / 10000
N_liu  = 8.6 * H_liu  * Q_liuout  / 10000
```

其中水头 H 由平均水位减去下游水位计算：

```
H_long(i,j) = 0.5 * (x(j+(i-1)*20) + x(j-1+(i-1)*20)) - Z_longxia(i,j)
H_liu(i,j)  = 0.5 * (x(20Y+j+(i-1)*20) + x(20Y+j-1+(i-1)*20)) - Z_liuxia(i,j)
```

下游水位 Z_xia 通过出库流量插值水位—流量曲线获得。

## 10. 模型局限与注意事项

1. **水位—库容关系** 使用线性插值（chz1/chz2），边界外直接返回端点值，无外推
2. **天然来水为确定性序列**（1970-2023 年历史实测），未考虑气候变化或随机径流情景
3. **各年水位通过起调水位串联**，不能并行计算
4. **约束主要通过截断+迭代修正满足**，而非罚函数或严格约束处理技术
5. **电站出力公式中的水能系数 K 值** 均为固定常数（8.0~8.6），未考虑机组效率变化
6. **协同度权重和阈值** 为固定值（如 26.63, 41.56, 1164 等），来源于规划文件，与具体需水情景相关
7. **模型当前仅覆盖龙羊峡—刘家峡梯级**，无扩展至更多水库的计划
8. **调沙流量参数基于经验确定**（非理论推导或实验标定）
